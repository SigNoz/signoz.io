# signoz.io MDX Components

This Storybook showcases the components available to docs and blog authors on
[signoz.io](https://signoz.io). Everything registered in
`components/MDXComponents.tsx` can be used directly in `data/docs/**` and
`data/blog/**` MDX files — this catalog documents what each component looks
like and which props it accepts.

- **Run locally:** `yarn storybook` (dev server with HMR at `localhost:6006`)
- **Static build:** `yarn build-storybook`, then `npx serve storybook-static`
- Stories render inside the same chrome as real docs pages: dark theme,
  design tokens, the `prose` typography wrapper, and a `RegionProvider`.

## Props tables

API tables on each docs page are generated from TypeScript types
(`react-docgen-typescript`). Components typed with a named props interface
(like `AdmonitionProps`) get full tables; components typed `(props: any)`
show an empty table. When touching an MDX component, prefer a named
`XProps` interface so its docs populate.
