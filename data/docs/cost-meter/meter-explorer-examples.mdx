These examples show common cost-analysis queries in Meter Explorer. All queries use meter metrics in the `signoz.meter` namespace and require a time range of at least 1 hour.

For the full list of available metrics and labels, see the [Metrics Reference](https://signoz.io/docs/cost-meter/meter-metrics-reference/).

## Log size by service

Find the total size of log records ingested by a specific service:

```
signoz.meter.log.size{service.name="demo-app"}
```

## Multi-service log comparison

Compare log ingestion across all services using a group-by:

```
signoz.meter.log.size{group-by:service.name}
```

## Log size by ingestion key

Analyze telemetry data attributed to a specific ingestion key:

```
signoz.meter.log.size{signoz.workspace.key.id = "01963e56-0bbb-7df5-b26c-2c4aa48b291a"}
```
