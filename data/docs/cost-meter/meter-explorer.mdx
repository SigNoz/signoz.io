Meter Explorer lets you analyze observability costs by querying granular meter metrics through the standard SigNoz query interface. Use it to drill into ingestion patterns, identify cost drivers by service or environment, and save recurring queries as views.

## What you can do with Meter Explorer

- Query any of the five core meter metrics (`signoz.meter.*`) across any time range ≥ 1 hour
- Filter and group results by service, environment, host, or ingestion key
- Compare ingestion across multiple services side-by-side
- Save common queries as views for recurring cost analysis

## Where to find it

Go to **Cost Meter** in the SigNoz side navigation, then select the **Meter Explorer** tab.

## How it works

### Metrics namespace

All meter metrics are namespaced under `signoz.meter` and follow standard SigNoz metric aggregation patterns. They are queryable through the same interface used for application metrics.

See the [Metrics Reference](https://signoz.io/docs/cost-meter/meter-metrics-reference/) for the full list of available metrics and their labels.

### Time range constraint

<Admonition type="info">
Meter data is aggregated over hourly intervals. Queries with time ranges under 1 hour return no data. Use time ranges of 1 hour or greater for all analysis.
</Admonition>

### Data retention

Meter data is retained for **1 year**, giving you access to historical trends for long-term cost analysis and capacity planning.

### Querying

Query patterns for meter data are identical to standard SigNoz metric queries — same operators, functions, and syntax. See the [Metrics Management Guide](https://signoz.io/docs/metrics-management/types-and-aggregation/) for a full reference.

### Saved views

Meter Explorer supports saved views. Once you configure a query you use regularly, save it as a view so you can return to it without rebuilding the query. See the [Saved Views documentation](https://signoz.io/docs/product-features/saved-view/#how-to-use-saved-views/) for details.
