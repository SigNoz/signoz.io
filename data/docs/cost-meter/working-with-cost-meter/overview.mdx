The Cost Meter dashboard is the main view for understanding how your observability usage is distributed across logs, traces, and metrics. Use it to compare total ingestion, identify expensive signals, and decide where to drill deeper with Meter Explorer or alerts.

## Overview

The Cost Meter dashboard is organized into four sections:

- **Total overview** — a combined view of all cost contributors: log record size, span size, and metric datapoints
- **Logs analysis** — log record count and total log data size ingested over the selected time range
- **Traces analysis** — span count and total span data size, useful for identifying high-volume services
- **Metrics analysis** — metric datapoint count, which directly maps to cardinality and billing

## How to use the dashboard

- Start with **Total overview** to understand the overall ingestion trend for the selected time range.
- Use the signal-specific sections to see whether logs, traces, or metrics are driving the largest share of ingestion.
- Move from the dashboard into [Meter Explorer](https://signoz.io/docs/cost-meter/meter-explorer/) when you need more detailed breakdowns by service, environment, host, or ingestion key.
- Set up [Meter Alerts](https://signoz.io/docs/cost-meter/alerts/) when you want to monitor a threshold instead of checking the dashboard manually.
