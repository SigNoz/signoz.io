This page documents all meter metrics exposed by SigNoz, their types, and the label dimensions available for filtering and grouping in Meter Explorer and Meter Alerts.

## Available metrics

SigNoz exposes five core meter metrics under the `signoz.meter` namespace:

| Metric name | Description | Type | Temporality |
|---|---|---|---|
| `signoz.meter.log.count` | Total number of log records ingested | Sum | Delta |
| `signoz.meter.log.size` | Total size of log records ingested (bytes) | Sum | Delta |
| `signoz.meter.span.count` | Total number of spans ingested | Sum | Delta |
| `signoz.meter.span.size` | Total size of spans ingested (bytes) | Sum | Delta |
| `signoz.meter.metric.datapoint.count` | Total number of metric datapoints ingested | Sum | Delta |

## Metric labels

Each meter metric carries the following labels, which can be used to filter or group results:

| Label | Description |
|---|---|
| `service.name` | Name of the service generating the telemetry data |
| `deployment.environment` | Deployment environment (e.g., `production`, `staging`, `development`) |
| `host.name` | Hostname of the system generating the data |
| `signoz.workspace.key.id` | ID of the ingestion key used to ingest the telemetry data |

## Data retention

Meter data is retained for **1 year**. This gives you access to historical ingestion data for long-term trend analysis and capacity planning.
