## Overview

SigNoz supports mobile application monitoring through OpenTelemetry instrumentation. By adding the OpenTelemetry SDK to your iOS or Android app, you can send traces, logs, and performance data to SigNoz. You get visibility into app behavior, API call latency, errors, and crashes alongside your backend telemetry.

### Supported Platforms

- **iOS** - Swift UI applications using the OpenTelemetry Swift SDK
- **Android** - Java and Kotlin applications using the OpenTelemetry Android agent, for traces, logs, and metrics
- **Cross-Platform** - Flutter applications for both iOS and Android
