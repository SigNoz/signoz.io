You should open the repo and browse the code and files as we go through the doc step by step.
### Step 1: Add interceptors to `client.Option`
Client applications and workers connect to the temporal service via `client.Dial` function which takes in client options as input (see the [connection.go file on GitHub](https://github.com/SigNoz/temporal-golang-opentelemetry/blob/main/helloworld/connection.go)). Here is the config that we use to connect to the temporal service:
```
options := client.Options{
HostPort:       hostPort,
Namespace:      namespace,
Interceptors:   []interceptor.ClientInterceptor{tracingInterceptor},
MetricsHandler: metricsHandler,
Logger:         logger,
}
```
For this to work we need to define `tracingInterceptor`, `metricsHandler` and `logger`. In the next steps, we will see how to properly set these up.
