The Azure Kubernetes Service (AKS) integration collects metrics and diagnostic logs from your AKS clusters. Once enabled, the SigNoz agent discovers AKS clusters in your monitored resource groups and configures telemetry collection.

<Admonition type="info">
This integration covers AKS resources of type `Microsoft.ContainerService/managedClusters` only. Other Container Service resource types are not collected.
</Admonition>

## Getting started

Connect your Azure subscription first. See [Azure One-Click Integrations](https://signoz.io/docs/integrations/azure/one-click-azure-integrations/) for setup instructions.

Once connected:

1. In SigNoz, navigate to **Integrations** > **Microsoft Azure**.
2. Select **Azure Kubernetes Service (AKS)** from the left panel.
3. Toggle **Log Collection** and **Metric Collection** on.

<Figure
  src="/img/docs/integrations/azure/azure-aks-enable.webp"
  alt="SigNoz Azure integration panel showing Azure Kubernetes Service (AKS) with Log Collection and Metric Collection toggles enabled"
  caption="Enable log and metric collection for Azure Kubernetes Service in the SigNoz UI"
  className="box-shadowed-image"
/>

The agent deploys the necessary Event Hubs and diagnostic settings in the background. Logs are collected using the `allLogs` category group, which captures every diagnostic log category exposed by AKS. Data starts flowing within a few minutes. Navigate to **Dashboards** and open the **Azure Kubernetes Service (AKS) Overview** dashboard to confirm metrics are appearing.

## Dashboards

The integration ships with a pre-built **Azure Kubernetes Service (AKS) Overview** dashboard. Pre-built dashboards are locked and cannot be edited. To customize, use **Export JSON** from the dashboard menu and import it as a new dashboard.

<Figure
  src="/img/docs/integrations/azure/azure-aks-dashboard.webp"
  alt="SigNoz dashboard showing Azure Kubernetes Service (AKS) Overview with CPU usage, memory working set, disk usage, and network bytes panels for cluster nodes"
  caption="Azure Kubernetes Service (AKS) Overview dashboard in SigNoz"
  className="box-shadowed-image"
/>

The dashboard groups 13 panels into five collapsible sections:

- **API Server** — CPU and memory usage percentage of the API server pod.
- **ETCD** — CPU, memory, and database usage percentage of ETCD instances.
- **Nodes Overview** — total allocatable CPU cores, total allocatable memory, and node status conditions for the cluster.
- **Enhanced Nodes Overview** — per-node CPU usage, memory working set, disk usage, and network in/out bytes.
- **Pods** — pod count by status phase.

### Filtering by subscription and cluster

The dashboard includes two variables so you can scope the view to a specific cluster:

- `azuremonitor.subscription_id` — your Azure subscription ID.
- `name` — the AKS cluster name. Options are populated dynamically from the metrics SigNoz has ingested.

Set both values at the top of the dashboard to filter every panel to a single cluster.
