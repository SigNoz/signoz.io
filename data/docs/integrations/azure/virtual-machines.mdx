The Azure Virtual Machines integration collects metrics from `Microsoft.Compute/virtualMachines` resources in your monitored resource groups. Once enabled, the SigNoz agent discovers Virtual Machines and configures Azure Monitor metric collection automatically.

## Getting started

Connect your Azure subscription first. See [Azure One-Click Integrations](https://signoz.io/docs/integrations/azure/one-click-azure-integrations/) for setup instructions.

Once connected:

1. In SigNoz, navigate to **Integrations** > **Microsoft Azure**.
2. Select **Virtual Machines** from the left panel.
3. Toggle **Metric Collection** on.

The agent updates the telemetry pipeline in the background. Metrics start flowing within a few minutes. Navigate to **Dashboards** and open the **Azure Virtual Machine Overview** dashboard to confirm metrics are appearing.

<Admonition type="info">
Log collection is not yet available for Azure Virtual Machines. Only metrics are collected.
</Admonition>

## What's collected

The integration collects 150+ Azure Monitor metrics across CPU, memory, availability, network, and disk I/O. Each metric family is exposed as multiple Azure Monitor statistics — typically `average`, `count`, `maximum`, `minimum`, and `total` — so each family below corresponds to several time series in SigNoz (for example, `azure_percentage_cpu_average`, `azure_percentage_cpu_maximum`, etc.).

## Dashboards

The integration includes a pre-built **Azure Virtual Machine Overview** dashboard. Pre-built dashboards are locked and cannot be edited. To customize, use **Export JSON** from the dashboard menu and import it as a new dashboard.

Use the variables at the top of the dashboard to filter by **Subscription ID** (`azuremonitor.subscription_id`) and individual **VM name** so you can focus on a specific Azure subscription or virtual machine.

The dashboard is grouped into three panel sections:

- **Availability / Memory / CPU**: VM Availability, Available Memory Percentage, and Percentage CPU.
- **Network**: Network In Total and Network Out Total.
- **Disk**: Disk Write Bytes, Disk Read Bytes, Disk Write Operations/Sec, and Disk Read Operations/Sec.
