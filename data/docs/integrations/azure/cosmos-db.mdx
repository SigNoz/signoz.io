The Azure Cosmos DB integration collects platform metrics and diagnostic logs from your Request Unit (RU) based Azure Cosmos DB accounts. Once enabled, the SigNoz agent discovers Cosmos DB account resources in your monitored resource groups and configures telemetry collection.

<Admonition type="info">
This integration requires SigNoz Azure agent version **v0.0.12** or later.
</Admonition>

This integration collects platform metrics for the `Microsoft.DocumentDB/databaseAccounts` resource type — the RU-based Azure Cosmos DB account.

<Admonition type="info">
A single account resource type (`Microsoft.DocumentDB/databaseAccounts`) is used across all Cosmos DB APIs — NoSQL, Gremlin, Table, MongoDB (RU), and Cassandra. Per-API request metrics (for example, Cassandra or Gremlin request charges) are only reported for the API your account is configured to use.

The Cassandra API within a Cosmos DB account is **not** the same as Azure Managed Instance for Apache Cassandra. If you run a Managed Instance for Apache Cassandra cluster, use the dedicated [Azure Cassandra DB integration](https://signoz.io/docs/integrations/azure/cassandra-db/) instead — its metrics are separate and are not duplicated here.
</Admonition>

## Getting started

Connect your Azure subscription first. See [Azure One-Click Integrations](https://signoz.io/docs/integrations/azure/one-click-azure-integrations/) for setup instructions.

Once connected:

1. In SigNoz, navigate to **Integrations** > **Microsoft Azure**.
2. Select **Cosmos DB** from the left panel.
3. Toggle **Log Collection** and **Metric Collection** on.

<Figure
  src="/img/docs/integrations/azure/azure-cosmosdb-enable.webp"
  alt="SigNoz Azure integration panel showing Cosmos DB with Log Collection and Metric Collection toggles enabled"
  caption="Enable log and metric collection for Azure Cosmos DB in the SigNoz UI"
  className="box-shadowed-image"
/>

The agent deploys the necessary Event Hubs and diagnostic settings in the background. Data starts flowing within a few minutes. Navigate to **Dashboards** and open the **Azure Cosmos DB Overview** dashboard to confirm metrics are appearing.

## Dashboards

The integration includes a pre-built Azure Cosmos DB dashboard. Pre-built dashboards are locked and cannot be edited. To customize, use **Export JSON** from the dashboard menu and import it as a new dashboard.

<Figure
  src="/img/docs/integrations/azure/azure-cosmosdb-dashboard.webp"
  alt="SigNoz dashboard showing Azure Cosmos DB metrics including total requests, RU consumption, throughput, storage, and latency"
  caption="Azure Cosmos DB dashboard in SigNoz"
  className="box-shadowed-image"
/>

Key panels include:
- Total requests and total request units (RU)
- Normalized RU consumption and provisioned throughput
- Data usage, index usage, and document quota
- Document count
- Server-side latency (direct) and service availability
