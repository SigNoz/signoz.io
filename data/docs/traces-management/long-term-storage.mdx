SigNoz Cloud supports two storage tiers for trace data. You can configure how long data stays in each tier to balance query performance against storage cost — useful for compliance, auditing, or long-term trend analysis.

## Storage tiers

| Tier | Description |
|---|---|
| **Hot storage** | Faster query response. Recommended for active debugging and recent data. |
| **Cold storage** | Slower query response (typically 3× slower than hot for a typical query). Lower cost. Suitable for historical data, compliance, and long-term retention. |

## Pricing

## FAQ

**How does querying in hot storage compare to cold storage?**

Cold storage is typically 3× slower for a typical query. The exact difference depends on query complexity and data volume.

**How do I enable long-term storage?**

This feature must be enabled per account. Contact SigNoz Cloud support via in-product chat or at cloud-support@signoz.io to get it activated.
