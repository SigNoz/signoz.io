SigNoz automatically populates a set of **calculated fields** from OpenTelemetry span attributes during trace processing. These fields provide convenient access to commonly used telemetry data without requiring direct attribute queries, and support both legacy and current OTel semantic conventions.

## Field summary

| Field | Type | Description |
|---|---|---|
| `response_status_code` | string | HTTP or RPC response status code |
| `http_url` | string | Full HTTP URL of the request |
| `external_http_url` | string | Hostname portion of the URL (client spans only) |
| `http_method` | string | HTTP request method |
| `external_http_method` | string | HTTP method (client spans only) |
| `http_host` | string | HTTP host or server address |
| `db_name` | string | Database name or namespace |
| `db_operation` | string | Database operation being performed |
| `has_error` | bool | `true` if the span's status code indicates an error |
| `is_remote` | bool | `true` if the span represents a remote call |

## Field derivation rules

### `response_status_code`

The HTTP or RPC response status code, extracted from various status code attributes.

**Source attributes (in priority order):**
- `http.status_code` — HTTP status code (legacy)
- `http.response.status_code` — HTTP response status code (current)
- `rpc.grpc.status_code` — gRPC status code
- `rpc.jsonrpc.error_code` — JSON-RPC error code

**Processing:** HTTP and gRPC codes accept string or integer input and are parsed to integer. JSON-RPC error codes are stored as-is. Final value is always stored as a string.

---

### `http_url`

The full HTTP URL of the request.

**Source attributes:**
- `http.url` — Full HTTP URL (legacy)
- `url.full` — Full URL (current)

**Processing:** Stored as-is. Populated for all span kinds.

---

### `external_http_url`

The **hostname** portion of the HTTP URL. Only populated for **client spans** (Kind = 3).

**Source attributes:**
- `http.url` — Full HTTP URL (legacy)
- `url.full` — Full URL (current)

**Processing:** Parses the URL and extracts the hostname. If parsing fails, stores the original value.

---

### `http_method`

The HTTP request method.

**Source attributes:**
- `http.method` — HTTP method (legacy)
- `http.request.method` — HTTP request method (current)

**Processing:** Stored as-is (e.g., `GET`, `POST`). Populated for all span kinds.

---

### `external_http_method`

The HTTP request method. Only populated for **client spans** (Kind = 3).

**Source attributes:** Same as `http_method`.

**Processing:** Identical to `http_method` for client spans.

---

### `http_host`

The HTTP host or server address.

**Source attributes (first match wins):**
- `http.host` (legacy)
- `server.address`
- `client.address`
- `http.request.header.host`

**Processing:** Stored as provided.

---

### `db_name`

The database name or namespace.

**Source attributes:**
- `db.name` — Database name (legacy)
- `db.namespace` — Database namespace (current)

**Processing:** Stored as provided.

---

### `db_operation`

The database operation being performed.

**Source attributes:**
- `db.operation` — Database operation (legacy)
- `db.operation.name` — Database operation name (current)

**Processing:** Stored as provided (e.g., `SELECT`, `INSERT`).

---

### `has_error`

A boolean indicating whether the span represents an error.

**Derivation:** Set to `true` if the span's status code equals `STATUS_CODE_ERROR` (value 2). Derived from the span's status, not from attributes.

---

### `is_remote`

A boolean indicating whether the span represents a remote call.

## Span kind reference

The span kind affects how certain fields are populated:

| Kind | Value | Effect on calculated fields |
|---|---|---|
| `CLIENT` | 3 | `external_http_url` and `external_http_method` are populated |
| All others | — | Standard processing; `external_*` fields are not set |

## Semantic convention support

Both legacy and current OTel semantic conventions are supported. When a span contains both, the system uses the first matching attribute encountered.

| Legacy attribute | Current attribute |
|---|---|
| `http.url` | `url.full` |
| `http.method` | `http.request.method` |
| `db.name` | `db.namespace` |
| `db.operation` | `db.operation.name` |

## Example

For a client span (Kind = 3) with these attributes:

```
http.method: "GET"
url.full: "https://api.example.com/users/123"
http.response.status_code: 200
```

The calculated fields would be:

| Field | Value |
|---|---|
| `http_method` | `"GET"` |
| `external_http_method` | `"GET"` |
| `http_url` | `"https://api.example.com/users/123"` |
| `external_http_url` | `"api.example.com"` |
| `response_status_code` | `"200"` |
