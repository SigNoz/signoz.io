Collection agents are pre-configured OpenTelemetry collectors that simplify the deployment and management of OpenTelemetry in your infrastructure. They gather telemetry data metrics, traces, and logs from your applications/systems and forward it to SigNoz.

### OpenTelemetry Collectors as Collection Agents
Collection agents leverage the power of OpenTelemetry collectors while removing the complexity of manual configuration. Instead of setting up OpenTelemetry from scratch, collection agents provide OpenTelemetry configurations tailored for specific environments and use cases.

Each collection agent is essentially an OpenTelemetry collector packaged with:

- **Platform-specific installation instructions**: Detailed guides for running OpenTelemetry in your environment
- **Pre-configured OpenTelemetry pipelines**: Ready-to-use receivers, processors, and exporters
- **Environment-optimized settings**: OpenTelemetry configurations tuned for each platform (Kubernetes, ECS, Fargate, etc.)

For example, the [k8s-infra](https://signoz.io/docs/opentelemetry-collection-agents/k8s/k8s-infra/overview) collection agent deploys OpenTelemetry collectors as a DaemonSet in your Kubernetes cluster, automatically collecting:

- Tails and parses logs generated by containers in the Kubernetes cluster.
- Gathers Traces from your Kubernetes Cluster generated by containers.
- Collects kubelet metrics and host metrics from each node in the Kubernetes cluster.
- Acts as a gateway to send any incoming OTLP telemetry data to the SigNoz.
