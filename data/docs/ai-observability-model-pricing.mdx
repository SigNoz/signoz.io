**Model pricing** is the settings tab of [AI Observability](https://signoz.io/docs/ai-observability/) where you set the price SigNoz uses to turn LLM token counts into cost. Each pricing rule maps one or more model names to a price for input tokens and a price for output tokens, in USD per one million tokens.

Use this page to add or change a pricing rule, and to price models that appear in your spans but have no rule yet.

<Admonition type="info">
AI Observability is available to every user and carries a **Beta** label in the side navigation. Any user can view pricing rules. Only Admins can add, edit, map, or delete them. For prerequisites, see the [AI Observability overview](https://signoz.io/docs/ai-observability/#prerequisites).
</Admonition>

## Open Model pricing

1. In the side navigation, open the **More** menu and select **AI Observability**.
2. In the tab bar at the top, select **Model pricing**.

The page has two tabs. **Model Costs** lists the pricing rules. **Unpriced models** lists the models that SigNoz found in your spans but cannot price.

## Model Costs tab

The **Model Costs** tab shows the pricing rules in a table, 20 rules per page.

| Column | What it shows |
| --- | --- |
| **Model** | The billing model name and its ID, for example `openai:gpt-4o`. |
| **Provider** | The provider of the model, for example OpenAI or Anthropic. |
| **Input / 1M** | The price for one million input tokens, in USD. |
| **Output / 1M** | The price for one million output tokens, in USD. |
| **Extra buckets** | The prices for cached tokens (Cache Read, Cache Write), if the rule has them. |
| **Source** | **Auto** for a default price from SigNoz, or **User override** for a price that an Admin set. |
| **Last seen** | The time since the rule was last updated or synced. |

To find a rule, type a model name or a provider name in the **Search by model or provider** box. To show only one type of rule, select **User override** or **Auto** in the source filter.

The URL keeps the search text, the source filter, and the page number. You can share the URL to show a teammate the same filtered table.

## Add a pricing rule

1. On the **Model Costs** tab, select **Add model cost**.
2. In **Billing Model ID**, type an ID for the rule, for example `openai:gpt-4o`.
3. Select the **Provider**.
4. In **Model name patterns (prefix match)**, add the model names that this rule prices. SigNoz compares each pattern with the start of the `gen_ai.request.model` value on a span.
5. In **Pricing (per 1M tokens, USD)**, type the **Input Cost** and the **Output Cost**. If the provider charges a different price for cached tokens, select **Add pricing bucket** and add a `cache_read` or `cache_write` price.
6. Select **Save**.

You cannot change the Billing Model ID or the Provider after you save the rule.

## Edit or delete a pricing rule

To edit a rule, open the menu (⋮) at the end of its row and select **Edit**. The drawer shows the same fields as a new rule.

<Figure
  src="/img/docs/ai/ai-observability/model-cost-drawer.webp"
  alt="Edit model cost drawer with Billing Model ID, Provider, Model name patterns, Source, and read-only pricing for an Auto-populated rule"
  caption="The Edit model cost drawer for a rule with default pricing"
/>

A rule with the **Auto-populated** source uses the default price from SigNoz, and you cannot change its prices. To set your own prices, change the source to **User override**. To go back to the default price, select **Auto-populated** again and confirm the reset. The reset discards your custom prices.

To delete a rule, open the menu (⋮) on its row, select **Delete**, and confirm.

## Price an unpriced model

The **Unpriced models** tab lists models that SigNoz found in spans but that match no pricing rule. SigNoz cannot calculate cost for spans from these models. A badge on the tab shows how many models are unpriced. Each row shows the model name from spans, the provider, and the span count.

To price a model:

1. In the **Map to billing model** column of the model, open the **Select / Create a pricing model** dropdown.
2. Do one of these steps:
   - To use the price of an existing rule, select that rule and then select **Map model**. SigNoz adds the model name as a pattern on the rule.
   - To set a new price, select **Create a new pricing model** at the bottom of the dropdown. The **Add model cost** drawer opens with the model name in **Billing Model ID**. Complete the drawer as in [Add a pricing rule](#add-a-pricing-rule).

When no models are unpriced, the tab shows "All models in your traces are priced."

## When price changes take effect

SigNoz calculates cost when it receives a span, not when you run a query. A price change applies to new spans only. The cost of spans that SigNoz already stored does not change. A change can take up to 24 hours to take effect.
