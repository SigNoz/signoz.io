Configure a notification channel to receive alert notifications. Navigate to **Alerts → Notification Channels** to create and manage channels.

## Manage the Channel List

The Notification Channels page lists every configured channel. In a workspace with no channels, it shows a **New channel** button and a **Read the setup guide** link.

<Figure
  src="/img/docs/notification-channels/empty-state.webp"
  alt="Empty Notification Channels page in SigNoz with the New channel button and the Read the setup guide link."
  caption="A workspace with no notification channels."
/>

- **New Channel**: opens the create form.
- **Columns**: shows or hides the **Type**, **Created At**, and **Updated At** columns.
- **Type filter**: pick a type in the **All types** dropdown next to the search box to show only that type. The create button then changes to match, for example **New Slack Channel**, and opens the form with that type selected.

<Figure
  src="/img/docs/alert-channels.webp"
  alt="SigNoz Notification Channels list with the Columns control, the New Channel button, and the type filter."
  caption="The Notification Channels page lists the configured channels."
/>

<Figure
  src="/img/docs/notification-channels/column-selector.webp"
  alt="Column selector popover on the SigNoz Notification Channels list with toggles for Type, Created At, and Updated At."
  caption="Use the Columns control to show or hide table columns."
/>

To set up a channel, pick its type below.
