Configure a notification channel to receive alert notifications. Navigate to **Settings → Notification Channels** (or **Alerts → Notification Channels**) to create and manage channels.

## The Notification Channels page

The Notification Channels page lists every configured channel. If the workspace has no channels yet, it shows an empty state with a **New channel** button and a **Read the setup guide** link instead of an empty table.

Once you have channels, the list gives you a few controls:

- **New Channel**: Opens the create form. The help icon sits to its right.
- **Columns**: Shows or hides the **Type**, **Created At**, and **Updated At** columns.
- **Type filter**: Narrows the list to one channel type. When a filter is active, the title reflects it (for example, **All Slack channels**) and the create button becomes **New [Type] Channel**, which opens the create form with that type pre-selected.
