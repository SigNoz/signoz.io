# CodeBlock variants playground

Internal visual / authoring reference for MDX fenced code blocks. Open at `/dev/codeblock/`. Not linked from docs nav.

**Defaults:** line numbers on · collapse when lines > 20 · starts **expanded** · GitHub Dark Dimmed / GitHub Light · system mono 14/24.

| Meta | Effect |
|------|--------|
| `lang:path` | Filename title in the chrome (not a tab underline) |
| `{5-9}` | Neutral (robin) line highlight |
| `{n}#cherry` / `#forest` / `#amber` / `#robin` | Sentiment highlights |
| `noLineNumbers` | Hide gutter |
| `minimap` | Right-side minimap strip |
| `collapse` / `collapse={N}` | Collapse controls when lines > 20 / > N |
| `noCollapse` | Never show collapse controls |
| `defaultCollapsed` | Start collapsed (only when collapse controls apply) |
| `<CodeTabs>` / `<CodeTab>` | In-chrome tabs (see §8) |

def resolve(flag):
    try:
        return provider.get(flag)
    except Exception as exc:
        raise RuntimeError(str(exc)) from exc


def evaluate(ctx):
    value = resolve(ctx.key)
    if value is None:
        return ctx.default
    return value


def main():
    print(evaluate(Context(key="dark-mode", default=False)))
    print(evaluate(Context(key="beta", default=True)))

## 8. In-chrome tabs (`CodeTabs`)

Prefer page-level `<Tabs>` / `<TabItem>` for docs. Use `<CodeTabs>` only when tabs should live **inside** the codeblock header (product-style chrome).

### Usage

Use JSX tabs wrapping normal fences (blank line between tags and fences helps MDX parse):

````md
<CodeTabs>
  <CodeTab value="http" label="HTTP" default>

```bash
curl https://example.com
```

  </CodeTab>
  <CodeTab value="grpc" label="gRPC">

```bash
grpcurl example.com:443 list
```

  </CodeTab>
</CodeTabs>
````

| Prop | On | Effect |
|------|-----|--------|
| `value` | `CodeTab` | Stable id for the tab (required) |
| `label` | `CodeTab` | Visible tab title (required) |
| `default` | `CodeTab` | Starts selected (first tab if omitted) |
| `icon` | `CodeTab` | Optional React node; defaults to file icon |
| `className` | `CodeTabs` | Optional wrapper class |

**Behavior notes**

- Copy in the header copies the **active** tab’s code only.
- Nested fences skip their own filename chrome (`insideTabs`) — the tab label is the title.
- Fence meta still works per tab: highlights, `minimap`, `noLineNumbers`, `collapse`, etc.
- Prefer `<region>` in ingestion endpoints so the docs region selector can substitute.
