## Common Query Issues

**Query Performance Problems**
- **Symptom**: Slow query execution
- **Potential Solutions**:
  - Check [time range selection](#performance-optimization)
  - Use [resource attributes](https://signoz.io/docs/userguide/field-context-data-types/) in WHERE clauses
  - Reduce [GROUP BY](https://signoz.io/docs/querying/aggregation-grouping/) cardinality
  - Increase aggregation intervals

**No Results Returned**
- **Check**: [Filter syntax](https://signoz.io/docs/userguide/search-syntax/) and attribute names
- **Verify**: Time range includes expected data
- **Confirm**: Service/attribute existence in the time period

**Unexpected Results**
- **Review**: Filter combinations ([AND vs OR logic](https://signoz.io/docs/userguide/operators-reference/))
- **Validate**: [Aggregation functions](https://signoz.io/docs/querying/aggregation-grouping/) match your intent
- **Check**: [Group By](https://signoz.io/docs/querying/aggregation-grouping/) attributes for proper categorization

## Performance Optimization

**Query**
1. **Filter early**: Apply restrictive [filters](https://signoz.io/docs/userguide/search-syntax/) first
2. **Limit scope**: Use specific time ranges
3. **Resource attribute awareness**: Leverage [resource attributes](https://signoz.io/docs/userguide/field-context-data-types/) to speed up queries
4. **Aggregation efficiency**: Choose appropriate time windows

**Dashboard Performance**
1. **Adjust refresh frequency**: Balance freshness with performance
2. **Optimize time ranges**: Avoid unnecessarily wide windows
3. **Limit concurrent queries**: Stagger dashboard loads
