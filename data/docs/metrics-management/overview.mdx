Metrics in SigNoz let you collect and visualize numerical time-series data from applications and infrastructure. Ingest from OpenTelemetry SDKs, the OTel Collector, or Prometheus-compatible sources and query them alongside your traces and logs.

## Key capabilities

- **Flexible ingestion**: Collect metrics from applications, infrastructure, and existing Prometheus setups. SigNoz also derives APM metrics (latency, error rate, throughput) from traces automatically.
- **Metrics Explorer**: Query and visualize any metric using the visual Query Builder, PromQL, or ClickHouse SQL — no dashboard required.
- **Dashboards and alerts**: Build custom [dashboards](https://signoz.io/docs/dashboards/overview/) or import pre-built templates. Configure [alerts](https://signoz.io/docs/alerts-management/overview/) to notify your team of anomalies.
- **Unified context**: Correlate metrics with traces and logs for faster root-cause analysis.

## Key product capabilities

### Metrics Explorer

The Metrics Explorer gives you a direct interface to query and understand your metric data:

- **Query and visualize** — select any metric, apply filters, choose aggregation functions, and group by attributes to build ad-hoc charts without creating a dashboard first
- **Metric types and aggregation** — understand how Counters, Gauges, Histograms, and Summaries are stored and which aggregations apply to each type
- **Metrics table** — browse all ingested metric names, their types, cardinality, and last-seen timestamps to audit what is being collected
