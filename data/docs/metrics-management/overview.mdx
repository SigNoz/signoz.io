## Overview

Metrics are numbers you collect over time to understand how your applications and infrastructure are behaving. You can use SigNoz to monitor systems with metrics — including CPU usage, memory consumption, and custom metrics your services report.

Metrics help you spot issues early, measure changes, and decide when to scale or optimize. Use this overview to decide where to go next — whether you want to start sending metrics, explore them in the UI, or learn about more advanced options.

## Types of Metrics

SigNoz supports four fundamental metric types that cover different measurement scenarios:

- Counter: Monotonically increasing values that only go up (for example, total requests, error count, bytes processed).
- Gauge: Values that can go up or down (for example, CPU usage, memory consumption, queue size).
- Histogram: Distribution of values in configurable buckets (for example, request latency, response sizes).
- Exponential Histogram: A histogram that uses logarithmic buckets to efficiently track values that span several orders of magnitude (for example, highly variable network latency).

Each metric type serves specific monitoring needs and comes with appropriate aggregation methods for meaningful analysis. Learn more in the detailed guide on [Metric Types and Aggregations](https://signoz.io/docs/metrics-management/types-and-aggregation/).

## Key capabilities

- **Send metrics from anywhere**
  - APM metrics: Out-of-the-box APM metrics are derived from traces at no extra cost, providing immediate visibility into application performance. [Learn more](https://signoz.io/docs/traces-management/guides/apm-metrics/).
  - Custom application metrics: Instrument your applications using OpenTelemetry SDKs for languages like Java, Node.js, Python, Go, and more. Capture custom business metrics alongside standard application performance metrics.
  - Infrastructure metrics: Collect system-level metrics from hosts, Kubernetes clusters, databases, and CI/CD pipelines using the OpenTelemetry Collector or native integrations.
  - Prometheus metrics: Seamlessly ingest existing Prometheus metrics using remote write configuration or scrape Prometheus exporters directly using the OpenTelemetry Prometheus receiver.
  - Cloud provider metrics: Use one-click integrations for AWS. Follow our simple guides for GCP and Azure to monitor cloud resources alongside your applications.

- **Explore metrics interactively**
  - The Metrics Explorer is SigNoz's interactive interface for discovering, querying, and visualizing metrics. It combines a visual query builder with powerful transformation and aggregation features so you can quickly answer operational questions and iterate on investigations.
  - Key capabilities include a searchable metric selector, aggregations and functions (sum, avg, percentiles, and more), grouping and breakdowns by attributes (such as service, host, region), filters for precise queries, and options to save and reuse queries.

- **Query, visualize, and alert on metrics**
  - Query Builder: Construct complex queries visually by selecting metrics, applying filters, choosing aggregations, and grouping by dimensions. [Learn more about Query Builder](https://signoz.io/docs/userguide/query-builder-v5/).
  - Dashboards: Create custom dashboards with multiple panels and visualization types, and use 40+ pre-built dashboard templates for common services like MongoDB, PostgreSQL, and ArgoCD. [Learn how to manage dashboards](https://signoz.io/docs/userguide/manage-dashboards/).
  - Alerts: Set up intelligent alerts based on metric thresholds, anomalies, or complex conditions. Configure multi-step rules with multiple notification channels including email, Slack, PagerDuty, and webhooks. [Configure metrics-based alerts](https://signoz.io/docs/alerts-management/metrics-based-alerts/).

- **Use advanced query languages when needed**
  - PromQL: Write Prometheus-style queries for advanced metric analysis and calculations. [Learn to write PromQL queries](https://signoz.io/docs/userguide/write-a-prom-query-with-new-format/).
  - ClickHouse SQL: Use ClickHouse SQL for complex analytics, joins, and custom aggregations on your metrics data. [Write ClickHouse queries for metrics](https://signoz.io/docs/userguide/write-a-metrics-clickhouse-query/).

- **Monitor infrastructure and correlate with applications**
  - Host monitoring: Track CPU, memory, disk, and network metrics for virtual machines and hosts.
  - Kubernetes monitoring: Get visibility into pods, nodes, namespaces, clusters, and deployments with automatic service discovery.
  - Unified observability: Correlate infrastructure health with application logs and traces for rapid root cause analysis. [Learn more about infrastructure monitoring](https://signoz.io/docs/infrastructure-monitoring/overview/).
