When using cloud provider metrics, you may notice a delay between when a metric is generated and when it appears in SigNoz. This is because metrics are fetched from the cloud provider's API, which introduces its own reporting lag before the data is available to scrape.

## AWS CloudWatch

AWS CloudWatch provides metrics in two resolutions:

| Resolution | Expected delay in SigNoz |
|---|---|
| 5-minute metrics | 5–15 minutes |
| 1-minute metrics | 2–3 minutes |

**Why the delay occurs:**

- CloudWatch makes 5-minute data available with a 5–10 minute lag after the measurement window closes.
- The CloudWatch API allows only one metric per request. Collecting multiple metrics requires multiple sequential requests, adding further delay.
- The availability of metrics can also vary by account level and service.
