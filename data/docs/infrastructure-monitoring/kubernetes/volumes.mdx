The **Volumes** view monitors PersistentVolumeClaim (PVC) storage consumption with color-coded usage indicators — green (0–60%), yellow (60–80%), and red (80–100%).

## Columns

| Column | Description |
|--------|-------------|
| **PVC Name** | PersistentVolumeClaim name |
| **Namespace Name** | Namespace the PVC belongs to |
| **Volume Capacity** | Total volume capacity |
| **Volume Utilization** | Percentage of capacity in use |
| **Volume Available** | Free space remaining on the volume |

## Volume Detail Page

Click a volume name to open the detail page.

### Metrics Tab

| Widget | Description |
|--------|-------------|
| **Volume Available** | Free space remaining over time |
| **Volume Capacity** | Total volume capacity over time |
| **Volume Inodes Used** | Number of inodes consumed |
| **Volume Inodes** | Total inodes available on the volume |
| **Volume Inodes Free** | Remaining inodes — volumes can run out of inodes before space if they contain many small files |
