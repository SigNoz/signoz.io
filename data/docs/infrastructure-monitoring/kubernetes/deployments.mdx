The **Deployments** view shows aggregated resource usage across all pods in each deployment.

## Deployments List Page Columns

### Deployment Name

Kubernetes Deployment name.

### Namespace Name

Namespace the Deployment belongs to.

### CPU Req Usage (%)

Average CPU request utilization across Deployment pods.

### CPU Limit Usage (%)

Average CPU limit utilization — approaching 100% = throttling risk.

### CPU Usage (cores)

Total CPU consumption across all Deployment pods.

### Mem Req Usage (%)

Average memory request utilization.

### Mem Limit Usage (%)

Average memory limit utilization — near 100% = OOMKill risk.

### Mem Usage (WSS)

Total working set memory across all Deployment pods.

## Deployment Detail Page

Click a Deployment name to open the detail page. The header shows **Deployment Name**, **Cluster Name**, and **Namespace Name**. The detail page includes four tabs: **Metrics**, **Logs**, **Traces**, and **Events**.

### Deployments Metrics - Charts and Panels

#### CPU Usage, Request, Limits

CPU consumption plotted against aggregate requests and limits.

#### Memory Usage, Request, Limits

Memory consumption against aggregate requests and limits.

#### Network IO

Total network throughput (transmit and receive) across all pods.

#### Network Error Count

Aggregated network errors.
