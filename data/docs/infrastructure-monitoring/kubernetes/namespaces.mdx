The **Namespaces** view shows aggregated resource usage per namespace, useful for cost allocation, ResourceQuota monitoring, and identifying resource-heavy namespaces.

  src="/img/docs/infrastructure-monitoring/kubernetes-namespaces-list.webp"

  caption="Namespaces List View"
  className="box-shadowed-image"
/>

## Namespaces List Page Columns

### Namespace Name

Kubernetes namespace name.

### Cluster Name

Cluster the namespace belongs to.

### CPU Usage (cores)

Total CPU consumption across all pods in the namespace.

### Mem Usage (WSS)

Total working set memory across all pods in the namespace.

## Namespace Detail Page

Click a namespace name to open the detail page. The header shows **Namespace Name** and **Cluster Name**. The detail page includes four tabs: **Metrics**, **Logs**, **Traces**, and **Events**.

### Namespaces Metrics - Charts and Panels

#### CPU Usage (cores)

Total CPU consumption over time — useful for ResourceQuota compliance.

#### Memory Usage (bytes)

Total working set memory over time.

#### Pods CPU (top 10)

Top CPU-consuming pods in this namespace.

#### Pods Memory (top 10)

Top memory-consuming pods in this namespace.

#### Network Rate

Aggregated network throughput (transmit and receive).

#### Network Errors

Aggregated network error count.

#### StatefulSets

Current vs desired pod counts for StatefulSets in this namespace.

#### ReplicaSets

Available vs desired replicas for ReplicaSets.

#### DaemonSets

Current vs desired scheduled nodes for DaemonSets.

#### Deployments

Available vs desired replicas for Deployments.
