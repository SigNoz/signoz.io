The **StatefulSets** view shows rollout status and resource utilization. StatefulSets update sequentially, so a stalled update shows Available < Desired for an extended period.

## StatefulSets List Page Columns

### StatefulSet Name

Kubernetes StatefulSet name.

### Namespace Name

Namespace the StatefulSet belongs to.

### Available

Pods running and passing readiness checks.

### Desired

Pods specified in the spec (replicas).

### CPU Req Usage (%)

Average CPU request utilization across all StatefulSet pods.

### CPU Limit Usage (%)

Average CPU limit utilization.

### CPU Usage (cores)

Total CPU consumption across all StatefulSet pods.

### Mem Req Usage (%)

Average memory request utilization.

### Mem Limit Usage (%)

Average memory limit utilization — near 100% = OOMKill risk.

### Mem Usage (WSS)

Total working set memory across all StatefulSet pods.

### Pod Counts by Phase

Counts of StatefulSet pods grouped by lifecycle phase (Pending, Running, Succeeded, Failed, Unknown).

## StatefulSet Detail Page

Click a StatefulSet name to open the detail page. The header shows **StatefulSet Name** and **Namespace Name**. The detail page includes four tabs: **Metrics**, **Logs**, **Traces**, and **Events**.

### StatefulSets Metrics - Charts and Panels

#### CPU Usage, Request, Limits

CPU consumption plotted against aggregate requests and limits.

#### CPU Request, Limit Utilization (%)

Percentage view of CPU utilization.

#### Memory Usage, Request, Limits

Memory consumption against aggregate requests and limits.

#### Memory Request, Limit Utilization (%)

Percentage view of memory utilization.

#### Network IO

Total network throughput across all StatefulSet pods.

#### Network Errors Count

Aggregated network errors.
