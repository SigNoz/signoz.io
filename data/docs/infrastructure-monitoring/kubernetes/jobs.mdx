The **Jobs** view tracks job completion status alongside resource consumption, useful for monitoring batch workloads and CronJobs.

## Jobs List Page Columns

### Job Name

Kubernetes Job name.

### Namespace Name

Namespace the Job belongs to.

### Successful

Pods that completed successfully.

### Failed

Pods that failed — non-zero values need investigation.

### Desired Successful

Pods needed for Job completion (the `completions` spec).

### Active

Pods currently running for this Job.

### CPU Req Usage (%)

Average CPU request utilization across Job pods.

### CPU Limit Usage (%)

Average CPU limit utilization.

### CPU Usage (cores)

Total CPU consumption across all Job pods.

### Mem Req Usage (%)

Average memory request utilization.

### Mem Limit Usage (%)

Average memory limit utilization.

### Mem Usage (WSS)

Total working set memory across all Job pods.

### Pod Counts by Phase

Counts of Job pods grouped by lifecycle phase (Pending, Running, Succeeded, Failed, Unknown).

## Job Detail Page

Click a Job name to open the detail page. The header shows **Job Name**, **Cluster Name**, and **Namespace Name**. The detail page includes four tabs: **Metrics**, **Logs**, **Traces**, and **Events**.

### Jobs Metrics - Charts and Panels

#### CPU Usage

Total CPU consumed by all Job pods.

#### Memory Usage, Request, Limits

Memory consumption against requests and limits.

#### Network IO

Network throughput across Job pods.

#### Network Errors Count

Aggregated network errors.
