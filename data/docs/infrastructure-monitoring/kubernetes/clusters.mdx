## Clusters List Page Columns

### Cluster Name

Kubernetes cluster name.

### CPU Usage (cores)

Total CPU consumption across all nodes.

### CPU Alloc (cores)

Total allocatable CPU — the cluster's scheduling capacity.

### Memory Usage (WSS)

Total working set memory across all nodes.

### Memory Allocatable

Total allocatable memory across all nodes.

## Cluster Detail Page

Click a cluster name to open the detail page. The header shows **Cluster Name**. The detail page includes four tabs: **Metrics**, **Logs**, **Traces**, and **Events**.

### Clusters Metrics - Charts and Panels

#### CPU Usage, Allocatable

Cluster CPU consumption vs total capacity — converging lines mean you need to scale.

#### Memory Usage, Allocatable

Cluster memory vs capacity — convergence means scheduling failures and evictions.

#### Ready Nodes

Number of nodes in Ready state, able to accept pods.

#### NotReady Nodes

Nodes unable to accept pods — kubelet crash, network partition, or resource exhaustion.

#### Deployments Available and Desired

Overview of deployment health — a gap indicates degraded deployments.

#### StatefulSet Pods

Current vs desired pods across all StatefulSets.

#### DaemonSet Nodes

Current vs desired nodes across all DaemonSets.

#### Jobs

Active, successful, and failed pods across all jobs.
