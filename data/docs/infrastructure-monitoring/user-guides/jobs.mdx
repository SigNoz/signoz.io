This page documents every column and chart in the **Infrastructure Monitoring > Kubernetes > Jobs** view.

## Columns

| Column | Metric | Description |
|--------|--------|-------------|
| **Job Name** | `k8s.job.name` resource attribute | Kubernetes job name. |
| **Active Pods** | `k8s.job.active_pods` | Pods currently running for this job. |
| **Successful Pods** | `k8s.job.successful_pods` | Pods that completed successfully. |
| **Failed Pods** | `k8s.job.failed_pods` | Pods that failed. Non-zero = job failures. |
| **Desired Successful** | `k8s.job.desired_successful_pods` | Pods needed for completion (the `completions` spec). |

### Column Color-Coding

**Failed Pods** highlights non-zero values in red.

## Widgets (Job Detail Page)

### Job Pod Counts

| Property | Value |
|----------|-------|
| **Metrics** | `k8s.job.active_pods`, `k8s.job.successful_pods`, `k8s.job.failed_pods`, `k8s.job.desired_successful_pods` |
| **Unit** | Count |
| **What it indicates** | Track job progress. For completed jobs, active = 0 and successful = desired. |

**Alerting:** Alert when `failed_pods > 0`. For CronJobs, alert when `successful_pods` doesn't increase within the expected schedule.

### Metric Sources

All job metrics come from the <a href="https://github.com/open-telemetry/opentelemetry-collector-contrib/tree/main/receiver/k8sclusterreceiver" target="_blank" rel="noopener noreferrer nofollow">k8scluster receiver</a>.
