This page documents every column and chart in the **Infrastructure Monitoring > Kubernetes > Namespaces** view.

## Columns

| Column | Metric | Description |
|--------|--------|-------------|
| **Namespace Name** | `k8s.namespace.name` resource attribute | Kubernetes namespace name. |
| **CPU Req/Limit Usage (%)** | Aggregated from pod metrics | Average CPU utilization across all pods in the namespace. |
| **CPU Usage (cores)** | Aggregated `k8s.pod.cpu.usage` | Total CPU consumption across all namespace pods. |
| **Memory Req/Limit Usage (%)** | Aggregated from pod metrics | Average memory utilization across all namespace pods. |
| **Memory Usage** | Aggregated `k8s.pod.memory.usage` | Total memory consumption across all namespace pods. |

### Column Color-Coding

Percentage columns use the same green/yellow/red progress bars as the Pods view.

## Widgets (Namespace Detail Page)

### Aggregated CPU Usage

| Property | Value |
|----------|-------|
| **Metric** | Aggregated `k8s.pod.cpu.usage` |
| **Unit** | Cores |
| **What it indicates** | Total CPU consumption by all pods in the namespace. Useful for cost allocation and ResourceQuota monitoring. |

**Alerting:** If using Kubernetes ResourceQuotas, alert when namespace CPU > **80%** of quota.

### Aggregated Memory Usage

| Property | Value |
|----------|-------|
| **Metric** | Aggregated `k8s.pod.memory.usage` |
| **Unit** | Bytes |

**Alerting:** If using Kubernetes ResourceQuotas, alert when namespace memory > **80%** of quota.

### Metric Sources

Namespace metrics are aggregated from pod-level metrics grouped by `k8s.namespace.name`. See [Pods Reference](https://signoz.io/docs/infrastructure-monitoring/user-guides/pods/) for individual pod metrics.
