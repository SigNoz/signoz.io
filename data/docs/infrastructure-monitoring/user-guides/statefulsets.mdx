This page documents every column and chart in the **Infrastructure Monitoring > Kubernetes > StatefulSets** view.

## Columns

| Column | Metric | Description |
|--------|--------|-------------|
| **StatefulSet Name** | `k8s.statefulset.name` resource attribute | Kubernetes StatefulSet name. |
| **Current Pods** | `k8s.statefulset.current_pods` | Pods running at the current revision. |
| **Desired Pods** | `k8s.statefulset.desired_pods` | Pods specified in the spec (replicas). |
| **Ready Pods** | `k8s.statefulset.ready_pods` | Pods that passed readiness checks. |
| **Updated Pods** | `k8s.statefulset.updated_pods` | Pods running the latest spec revision. During rolling updates, this increases as pods are replaced. |

### Column Color-Coding

If **Ready** < **Desired**, the StatefulSet is degraded. StatefulSets update sequentially, so a stalled update shows `updated < desired` for an extended period.

## Widgets (StatefulSet Detail Page)

### Current vs Desired Pods

| Property | Value |
|----------|-------|
| **Metrics** | `k8s.statefulset.current_pods`, `k8s.statefulset.desired_pods` |
| **Unit** | Count |

**Alerting:** Alert when `current < desired` for **10 min**. A single stuck pod blocks subsequent updates.

### Ready Pods

| Property | Value |
|----------|-------|
| **Metric** | `k8s.statefulset.ready_pods` |

**Alerting:** Alert when `ready < desired` for **5 min**.

### Updated Pods

| Property | Value |
|----------|-------|
| **Metric** | `k8s.statefulset.updated_pods` |
| **What it indicates** | Tracks rollout progress. |

**Alerting:** During rollouts, alert if unchanged for **15 min** — update is stalled.

### Metric Sources

All StatefulSet metrics come from the <a href="https://github.com/open-telemetry/opentelemetry-collector-contrib/tree/main/receiver/k8sclusterreceiver" target="_blank" rel="noopener noreferrer nofollow">k8scluster receiver</a>.
