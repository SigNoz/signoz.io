SigNoz Infrastructure Monitoring gives you a unified view of host and Kubernetes performance, traces, and logs. Use it to understand how infrastructure health impacts your applications and quickly drill from high-level lists into a single host, node, or pod.

<GetStartedInfrastructureMonitoring variant="showcase" />

## Overview

Infrastructure Monitoring includes two main views:

- **Hosts** – monitor physical or virtual machines with CPU, memory, disk, and network metrics, plus correlated traces and logs.
- **Kubernetes** – monitor clusters, nodes, namespaces, deployments, and pods with resource utilization and workload health.

Both views share common controls for time range, filtering, and navigation so you can move between metrics, traces, logs, and events without losing context.

### Host List View

The main screen of the Host interface displays a list of all monitored hosts along with key metrics. The table uses color-coded progress bars for CPU and memory usage so you can spot outliers at a glance.

<Figure
  src="/img/docs/infrastructure-monitoring/hosts-list.webp"

  caption="Host List"
  className="box-shadowed-image"
/>

#### Table Columns

- **Hostname**: System hostname or identifier
- **Status**: Current operational status — `ACTIVE` or `INACTIVE`
- **CPU Usage**: CPU utilization percentage with a progress bar
- **Memory Usage**: Memory usage percentage with a progress bar
- **IOWait**: Percentage of time the CPU is waiting for I/O operations
- **Load Avg**: System load average value

**Features:**
- **Filters sidebar** on the left to narrow hosts by Host Name, OS Type, or Environment
- **Search Filter** bar to query hosts by any attribute
- **Group By** dropdown to group hosts by a selected attribute
- **Sortable columns** — click any column header to sort
- **Total count** displayed at the bottom (e.g., "Showing 1 - 4 of 4 Hosts")
- **Paginated results** with configurable page size

### Host Details

Click a hostname to open the detail view. The header displays the host's status, operating system, CPU usage, and memory usage at a glance.

The detail view includes five tabs: **Metrics**, **Logs**, **Traces**, **Containers**, and **Processes**.

### Metrics Tab

Monitor host performance metrics across customizable time periods. Charts are zoomable — click and drag to zoom into a specific time range.

<Figure
  src="/img/docs/infrastructure-monitoring/host-metrics-details.webp"
  alt="Host Metrics Tab showing CPU Usage, Memory Usage, System Load Average, and Network usage charts"
  caption="Metrics Tab"
  className="box-shadowed-image"
/>

**Available Metrics:**

##### System Performance
- **CPU Usage**: Overall CPU utilization broken down by idle, user, system, wait, softirq, steal, and interrupt
- **Memory Usage**: Physical memory consumption showing free, used, cached, slab reclaimable, and slab unreclaimable
- **System Load Average**: Average system load over time
- **Queue Size**: Number of processes waiting for CPU time

##### Network Performance
- **Network Usage (Bytes)**: Inbound and outbound network traffic in bytes
- **Network Usage (Packets/s)**: Packet rate for network interfaces
- **Network Errors**: Count of network interface errors
- **Network Drops**: Number of dropped network packets
- **Network Connections**: Active network connection count

##### Disk Performance
- **System Disk I/O (Bytes)**: Total bytes read/written to disk
- **System Disk Operations/s**: Rate of read/write operations
- **Disk Operations Time**: Average time taken for disk operations

**Time Range Selection:**
- Choose from preset time ranges (e.g., last 30 minutes, last 24 hours)
- Set custom time ranges using the date-time picker
- Change your timezone according to your preference

### Traces Tab

View and analyze distributed traces associated with the selected host.

- **Service name**: Focus on traces from specific services
- **Operation type**: Filter by specific operations or endpoints (e.g., GET, POST)

### Logs Tab

Access and search through host logs with powerful filtering capabilities.

### Kubernetes Cluster View

The Kubernetes monitoring interface provides real-time visibility into your Kubernetes cluster. The left sidebar lets you switch between different resource types, and each list uses color-coded progress bars to highlight resource utilization.

<Figure
  src="/img/docs/infrastructure-monitoring/kubernetes-list.webp"
  alt="Kubernetes Pods View showing pod list with CPU and memory progress bars"
  caption="Kubernetes Cluster Overview — Pods View"
  className="box-shadowed-image"

### Kubernetes Monitoring Views

The sidebar on the left lists all available resource types. Click any to switch views:

- **Pods** *(Default)*: Displays all active pods with CPU and memory utilization progress bars
- **Nodes**: Performance and resource allocation for individual nodes
- **Namespaces**: Resource usage aggregated per namespace
- **Clusters**: Overview of resource allocation across clusters
- **Deployments**: Deployment statuses, availability, and resource consumption
- **Jobs, DaemonSets, StatefulSets, and Volumes**: Monitoring of specific Kubernetes workloads

### Pods View: Monitoring Kubernetes Pods

The **Pods View** provides real-time visibility into pod resource utilization with color-coded progress bars — green for normal, yellow for elevated, and red for critical usage.

#### Table Columns

- **Pod Name**: Name of the Kubernetes pod
- **CPU Req Usage (%)**: Percentage of requested CPU being utilized, shown as a progress bar
- **CPU Limit Usage (%)**: Percentage of CPU limit being used, shown as a progress bar
- **CPU Usage (cores)**: Actual CPU consumption in cores
- **Memory Req Usage (%)**: Percentage of requested memory being used
- **Memory Limit Usage (%)**: Percentage of allocated memory limit being used
- **Memory Usage**: Total memory consumption in bytes

**Features:**
- **Filters sidebar** on the left with checkboxes for Pod, Namespace, Node, and Cluster
- **Search Filter** bar to query pods by any attribute
- **Group By** dropdown to group pods by Namespace, Node, or Deployment
- **Sortable columns** — click any column header to sort alphabetically or by value
- **Total count** displayed at the bottom (e.g., "Showing 1 - 10 of 51 Pods")
- **Paginated results** with configurable page size

### Pod Details

Click a pod name to open the detail view. The header shows the pod's **Namespace**, **Cluster Name**, and **Node**.

The detail view includes four tabs: **Metrics**, **Logs**, **Traces**, and **Events**.

### Metrics Tab: Pod Performance Monitoring

The **Metrics Tab** provides zoomable charts for CPU, memory, and network performance. Click and drag on any chart to zoom into a specific time range.

<Figure
  src="/img/docs/infrastructure-monitoring/kubernetes-pod-metrics.webp"
  alt="Pod Metrics showing CPU Usage and CPU Request/Limit Utilization charts"
  caption="Pod Metrics View"

/>

### Available Metrics

#### CPU Metrics
- **CPU Usage (Cores)**: Real-time and historical CPU consumption with min, avg, and max values
- **CPU Request, Limit Utilization (%)**: CPU requests vs. limits to prevent over-allocation

#### Memory Metrics
- **Memory Usage (Bytes)**: Real-time memory consumption trends
- **Memory Request, Limit Utilization (%)**: Memory utilization compared to requests and limits
- **Memory by State**: Differentiates memory into RSS memory, working set memory, and cache memory
- **Memory Major Page Faults**: Tracks page faults affecting performance

#### Container-Specific Metrics
- **CPU Usage by Container**: CPU utilization at the container level within the pod
- **CPU Request, Limit Utilization by Container**: Container-level CPU constraints
- **Memory Usage by Container**: Memory usage for each container in the pod
- **Memory Request, Limit Utilization by Container**: Container memory efficiency

#### Network Metrics
- **Network Rate (Bytes/s)**: Network traffic sent (transmit) and received (receive)
- **Network Errors**: Network-related failures at the interface level

#### File System Metrics
- **File System Usage (Bytes)**: Disk space usage over time
