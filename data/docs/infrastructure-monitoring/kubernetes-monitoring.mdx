The Kubernetes Monitoring interface provides real-time visibility into your Kubernetes cluster. The left sidebar lets you switch between different resource types, and each list uses color-coded progress bars to highlight resource utilization.

## Monitoring Views

The sidebar on the left lists all available resource types. Click any to switch views:

- **[Pods](https://signoz.io/docs/infrastructure-monitoring/kubernetes/pods/)** *(Default)*: CPU and memory utilization with request/limit percentages per pod
- **[Nodes](https://signoz.io/docs/infrastructure-monitoring/kubernetes/nodes/)**: CPU and memory usage vs allocatable capacity per node
- **[Namespaces](https://signoz.io/docs/infrastructure-monitoring/kubernetes/namespaces/)**: Resource usage aggregated per namespace
- **[Clusters](https://signoz.io/docs/infrastructure-monitoring/kubernetes/clusters/)**: Resource allocation and capacity across clusters
- **[Deployments](https://signoz.io/docs/infrastructure-monitoring/kubernetes/deployments/)**: Availability, CPU, and memory across deployment pods
- **[Jobs](https://signoz.io/docs/infrastructure-monitoring/kubernetes/jobs/)**: Active, successful, and failed pod counts with resource usage
- **[DaemonSets](https://signoz.io/docs/infrastructure-monitoring/kubernetes/daemonsets/)**: Available vs desired nodes with resource usage
- **[StatefulSets](https://signoz.io/docs/infrastructure-monitoring/kubernetes/statefulsets/)**: Available vs desired pods with resource utilization
- **[Volumes](https://signoz.io/docs/infrastructure-monitoring/kubernetes/volumes/)**: PersistentVolumeClaim usage, capacity, and inodes

## Common Controls

All Kubernetes views share these controls:

### Quick Filters Sidebar

The left sidebar provides filter checkboxes for narrowing results. Available filters vary by view but commonly include:
- **Pod**, **Namespace**, **Node**, **Cluster**
- **Deployment**, **StatefulSet**, **DaemonSet**, **Job**
- **Environment**

Each filter section is expandable, supports search, and allows multi-select with "Only" toggle and "Clear All" options.

### Search Filter

The search bar at the top lets you query entities by any attribute using the query builder.

### Group By

Use the **Group By** dropdown to group entities by an attribute such as `k8s.node.name`, `k8s.namespace.name`, `k8s.deployment.name`, or `k8s.cluster.name`. When a group is selected, the table displays group header rows that you can expand to see individual entities within each group.

### Columns Selector

Click the columns icon in the toolbar to open the **Columns** panel. It shows the currently added columns and lets you add or remove columns to customize the table view.

<Figure
  src="/img/docs/infrastructure-monitoring/kubernetes-columns-selector.webp"
  alt="Columns selector panel showing added and available columns"
  caption="Columns selector for customizing table columns"
  className="box-shadowed-image"
/>

### Detail Page

Click any entity name to open its detail page. Every detail page includes four tabs — **Metrics**, **Logs**, **Traces**, and **Events** — so you can correlate infrastructure performance with application behavior.
