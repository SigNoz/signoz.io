## Integration with Pagerly

Pagerly is an on-call and incident management product for Slack and Microsoft Teams. SigNoz sends alerts to Pagerly through the existing **Webhook** channel, using the Pagerly Prometheus inbound integration.

1. In Pagerly, open <a href="https://workspace.pagerly.io/inbound" target="_blank" rel="noopener noreferrer nofollow">Inbound Integrations</a> and click **Add Alert Integration**.
2. Enter a display name, select the team, select **Prometheus**, and click **Add Integration**.
3. Copy the webhook that Pagerly generates for the integration.
4. In SigNoz, go to **Alerts > Notification Channels** and click **New Alert Channel**. Enter a name, select **Webhook** as the type, and paste the webhook URL into **Webhook URL**.
5. Click **Test** to send a sample alert, then click **Save**.

### How alerts map to Pagerly incidents

| SigNoz alert field | Pagerly incident field |
| :--- | :--- |
| `labels.alertname` | Title |
| `annotations.description` | Description |
| `generatorURL` | Link back to SigNoz |
| `status: firing` | Opens the incident |
| `status: resolved` | Resolves the incident |

## Configure programmatically

Since this integration uses the Webhook channel, you can configure it programmatically using the same mechanism as described in the [Webhook](https://signoz.io/docs/alerts-management/notification-channel/webhook/#configure-programmatically) section.
