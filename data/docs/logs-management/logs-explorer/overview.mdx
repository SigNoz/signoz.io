The Logs Explorer is SigNoz's primary interface for searching, filtering, and analyzing log data. Switch between List, Time Series, and Table views, stream logs in real time, and pivot directly to correlated traces.

## What you can do with Logs Explorer

- **Search and filter** — Query any log attribute using the Query Builder or the Quick Filters sidebar.
- **Aggregate and visualize** — Plot log volumes over time, group by any attribute, and compare multiple queries on a single chart.
- **Switch views** — Toggle between List (raw lines), Time Series (volume chart), and Table (structured columns) for the same query.
- **Live tail** — Stream logs in real time without page refreshes.
- **Correlate with traces** — Jump from any log line directly to its correlated distributed trace.
- **Export to dashboards** — Add any query result as a dashboard panel in one click.
- **Create alerts** — Set threshold or anomaly alerts directly from a query result.

## Where to find it

Go to **Logs → Logs Explorer** in the SigNoz sidebar.

## How it works

Logs Explorer queries your indexed log fields. Fields marked as **Selected** are indexed and support fast, auto-suggested filtering in the Query Builder. **Interesting** fields are stored but unindexed — you can still query them manually.

The left panel holds [Quick Filters](/docs/logs-management/features/logs-quick-filters) for the most common attributes (severity, service, hostname, Kubernetes labels). The main panel runs your [Query Builder](/docs/userguide/logs_query_builder) queries and displays results.
