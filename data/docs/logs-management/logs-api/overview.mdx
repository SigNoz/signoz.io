The SigNoz Logs API lets you query log data programmatically — search by attribute, paginate through large result sets, and run aggregations. Use it to build integrations, export data, or embed log queries in your own tooling.

## What you can do with the Logs API

- **Search logs** — Filter by any attribute, resource, or log field with the same filter expressions used in the Logs Explorer.
- **Paginate results** — Retrieve logs in batches using `offset` and `limit`.
- **Aggregate logs** — Count, group, and summarize log data (e.g., error counts by service over time).
- **Deep link to Explorer** — Construct URLs that open the Logs Explorer with a pre-filled query.

## API endpoint

All Logs API requests use:

```
POST https://{your-signoz-domain}/api/v5/query_range
```

Replace `{your-signoz-domain}` with your instance URL (e.g., `example.signoz.io`).

## Authentication

Every request requires an API key in the header:

```
SIGNOZ-API-KEY: {YOUR_API_KEY}
```

To create an API key: go to **Settings → API Keys** in SigNoz. Only users with the **Admin** role can create or manage API keys.

:::tip
Store your API key in a secrets manager or environment variable — never hardcode it in source code.
:::
