## Overview

Quick Filters lets you narrow down logs by the most common attributes — severity, service, environment, hostname, and Kubernetes labels — directly from a sidebar panel without writing a query.

:::info Prerequisites
- Logs are flowing into SigNoz.
- Resource attributes are set on your logs. See [Set Resource Attributes](/docs/logs-management/guides/set-resource-attributes-for-logs/).
:::

## Steps

### Step 1: Open Logs Explorer

**Action:** Go to **Logs → Logs Explorer** in the SigNoz sidebar.

### Step 2: Locate the Quick Filters panel

**Action:** The Quick Filters panel is on the left side of the Logs Explorer page.

  <img

### Step 3: Select a filter category and value

**Action:** Click a filter category (for example, **Severity Text** or **Service Name**) to expand it, then select the values you want to include.

The Logs Explorer updates automatically as you select values — no need to click "Apply".

### Step 4: Sync filters across multiple queries

**Action:** If you have multiple queries open, check the **Filters For** label at the top of the panel — it shows which query is currently in sync.

<figure data-zoomable align="center">
  <img src="/img/docs/logs-management/ui/filter-sync.webp" alt="Filter sync in Quick Filters" />
  <figcaption>
    <i>Filter sync indicator — shows which query receives filter changes</i>
  </figcaption>
</figure>

To switch sync to a different query, interact with that query (click into it). The last-touched query is always the one in sync.

### Step 5: Clear filters

**Action:** Click **Clear All** next to a filter category to reset it, or click the **Reset** button at the top of the panel to clear all active filters for the synced query.

## Available Filters

| Filter | What it filters | OTel attribute |
|---|---|---|
| Severity Text | Log level (INFO, ERROR, DEBUG, FATAL, …) | `severity_text` |
| Environment | Source environment (production, staging, …) | `resource[deployment.environment]` |
| Service Name | Name of the emitting service | `resource[service.name]` |
| Hostname | Machine or instance hostname | `resource[host.name]` |
| K8s Cluster Name | Kubernetes cluster name | `resource[k8s.cluster.name]` |
| K8s Deployment Name | Kubernetes deployment name | `resource[k8s.deployment.name]` |
| K8s Namespace Name | Kubernetes namespace | `resource[k8s.namespace.name]` |
| K8s Pod Name | Kubernetes pod name | `resource[k8s.pod.name]` |

:::tip
To map log body fields to resource attributes (e.g., extract a hostname from a log line), use [Log Pipelines](/docs/logs-pipelines/introduction/).
:::
