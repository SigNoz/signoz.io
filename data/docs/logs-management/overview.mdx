## Key Capabilities

- **Flexible Ingestion** — Collect logs from files, stdout, FluentBit/FluentD/Logstash, OpenTelemetry SDKs, HTTP endpoints, and cloud services.
- **Logs Explorer** — Search, filter, and analyze logs with List, Time Series, and Table views. Stream live logs in real time. [Learn more →](/docs/product-features/logs-explorer/)
- **Query Builder** — Build advanced queries with aggregations, grouping, and multi-query comparisons. [Learn more →](/docs/userguide/logs_query_builder/)
- **Log Pipelines** — Parse, transform, and enrich logs before storage using SigNoz's functional pipeline builder. [Learn more →](/docs/logs-pipelines/introduction/)
- **Alerts** — Set up alerts on log patterns, counts, or attribute values. [Learn more →](/docs/alerts-management/log-based-alerts/)
- **Unified Context** — Correlate logs with traces and metrics for faster root-cause analysis. [Learn more →](/docs/traces-management/guides/correlate-traces-and-logs/)
