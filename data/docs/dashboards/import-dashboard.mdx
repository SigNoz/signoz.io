SigNoz provides a variety of out-of-the-box dashboards that you can use to monitor your applications and infrastructure. 

## Steps to import dashboard

### Step 1: Find a dashboard template

Navigate to the [Dashboards](https://signoz.io/docs/dashboards/dashboard-templates/overview/) page to explore the available dashboard templates. You can find dashboards for 
various services like databases, web servers, and more.

### Step 2: Copy/Download the dashboard JSON

You can choose any dashboard you’d like to use. For instance, to monitor a MySQL database, click the [MySQL dashboard](https://signoz.io/docs/dashboards/dashboard-templates/mysql/) icon. On that page, you’ll see options to copy or download the dashboard JSON file.

### Step 3: Import the dashboard in SigNoz

In your SigNoz UI, go to the **Dashboards** page and click on the **+ New dashboard** button. You will see an option to **Import JSON**. 

<Figure
  src="/img/docs/dashboards/import-dashboard/import-dashboard-json.webp"
  alt="Import JSON"
  caption="Import JSON"
/>

You can either paste the JSON that you copied or upload the JSON file that you downloaded.

<Figure
  src="/img/docs/dashboards/import-dashboard/paste-or-upload-dashboard-json.webp"
  alt="Paste or Upload Dashboard JSON"
  caption="Paste or Upload Dashboard JSON"
/>

Once the JSON is imported, you will see the new dashboard on your dashboards page.

<Admonition type="info" title="Importing a legacy dashboard export">
Dashboards exported from an older SigNoz version use the legacy V1 JSON format. You can import that JSON directly here. SigNoz detects the V1 format and converts it to the current dashboard schema on the server, so no manual reshaping is needed before import.
</Admonition>

<Admonition type="warning">
Import fails with an error toast if the dashboard's `image` field holds an invalid value, such as a remote URL, a `javascript:` URI, a non-image data URI, or raw markup. Set `image` to an `/assets/Icons/<name>` path, an `/assets/Logos/<name>` path, or a base64 image data URI. See [Icon paths in dashboard JSON](https://signoz.io/docs/userguide/manage-dashboards/#icon-paths-in-dashboard-json) for the accepted formats.
</Admonition>
