Use public sharing when you want to make a dashboard available with a link outside the authenticated SigNoz UI. Dashboards built in either the classic or the new (v2) editor can be shared, and the public view automatically renders the correct viewer for each.

<Admonition type="info">
  Public sharing is available on SigNoz Cloud and Enterprise (self-hosted) plans.
</Admonition>

## Enable Public Sharing

1. From the sidebar, choose **Dashboards** and select the respective dashboard you want to share publicly.
2. Open the configuration drawer for that dashboard by clicking the **Configure** icon.
3. In the configuration drawer, select **Publish**.
4. To allow viewers to change the time range on the public dashboard, toggle the **Enable time range** option.
5. Choose the **Default time range** that the public dashboard should use.

<Admonition type="info">
  **Important**: If the time range option is disabled, viewers will only be able to see the
  dashboard for the specified default time range.
</Admonition>

6. Click the **Publish Dashboard** button to enable public sharing.
7. A publicly shareable link will be generated, which you can use to provide public access to the dashboard.

<Figure

  alt="Public sharing configuration in SigNoz"
  caption="Once published, copy the public dashboard URL or open it directly. Dashboard variables won't work in public dashboards."
/>

Dashboards authored in the new (v2) editor are supported alongside classic dashboards. The person sharing does nothing differently: the public link detects the dashboard format and renders the matching viewer for anonymous visitors.

## View a Public Dashboard

Anyone with the link opens a read-only view. It shows the SigNoz branding, the dashboard title, section headings, and panels in a layout matching the editor. There are no edit controls or drill-down navigation, and panel queries execute for anonymous visitors so charts render live data.

When you publish with **Enable time range** turned on, the public view header also includes a time range picker and an auto-refresh control:

- **Time range picker**: viewers can switch the displayed window between relative presets (for example, Last 30 minutes, Last 6 hours) or a custom absolute date range.
- **Auto-refresh**: viewers can keep panels live by choosing a refresh interval (for example, 5 seconds, 1 minute) without logging in.

<Figure
  src="/img/docs/dashboards/public-sharing/public-view-time-controls.webp"
  alt="Public dashboard view showing the time range picker and auto-refresh control in the header with panels rendering data"
  caption="The public view header shows the dashboard title, time range picker, and auto-refresh control while panels render live data."
/>

<Admonition type="info">
  Auto-refresh applies only to relative time presets. If a viewer selects a custom (absolute) time
  range, the auto-refresh control is automatically paused and resumes when they switch back to a
  relative preset.
</Admonition>

  caption="Selecting a custom absolute time range pauses the auto-refresh control until a relative preset is chosen again."

## Disable Public Sharing

1. From the sidebar, choose **Dashboards** and select the respective dashboard for which you want to revoke public access.
2. Open the configuration drawer for that dashboard by clicking the **Configure** icon.
3. Navigate to the dashboard configuration section and select **Publish**.
4. To disable public sharing for the dashboard, click the **Unpublish dashboard** button.
