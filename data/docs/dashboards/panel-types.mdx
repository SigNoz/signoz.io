SigNoz dashboards support seven panel types. Each is designed for a different kind of data and analysis goal. Choose based on the question you want to answer.

## Choosing a panel type

| Panel type | Best for | Signals |
|---|---|---|
| [Timeseries](https://signoz.io/docs/dashboards/panel-types/timeseries/) | Trends over time — request rate, CPU usage, error rate | Metrics, Traces, Logs |
| [Bar Chart](https://signoz.io/docs/dashboards/panel-types/bar/) | Comparing categories over time; supports stacked view | Metrics, Traces, Logs |
| [Histogram](https://signoz.io/docs/dashboards/panel-types/histogram/) | Distribution of values — latency buckets, request sizes | Metrics, Traces, Logs |
| [Value](https://signoz.io/docs/dashboards/panel-types/value/) | Single aggregated number — current p99 latency, total errors | Metrics, Traces, Logs |
| [Table](https://signoz.io/docs/dashboards/panel-types/table/) | Tabular data with group-by dimensions | Metrics, Traces, Logs |
| [Pie Chart](https://signoz.io/docs/dashboards/panel-types/pie/) | Proportional breakdown of categories | Metrics, Traces, Logs |
| [List](https://signoz.io/docs/dashboards/panel-types/list/) | Raw log lines or spans with infinite scroll | Logs, Traces |

## Timeseries

A line chart that plots metric values over time. Use it for anything that changes continuously — request rates, CPU usage, memory, error counts.

Supports fill gaps, soft min/max axis control, Y-axis units, and threshold lines.

→ [Timeseries reference](https://signoz.io/docs/dashboards/panel-types/timeseries/)

## Bar Chart

A bar chart that compares values across categories over time. Use it when discrete differences matter more than the exact trend shape. Supports stacked mode to show each series' contribution to the total.

→ [Bar Chart reference](https://signoz.io/docs/dashboards/panel-types/bar/)

## Histogram

Groups values into buckets and shows their frequency. Use it to understand the distribution of a dataset — for example, how many requests fell into each latency range. Supports configurable bucket count and merging multiple series into one histogram.

→ [Histogram reference](https://signoz.io/docs/dashboards/panel-types/histogram/)

## Value

Displays a single number aggregated over the selected time range. Use it for at-a-glance KPIs — average error rate, max latency, total request count. Supports reduce functions (avg, sum, max, min, latest) and threshold-based colour coding.

→ [Value reference](https://signoz.io/docs/dashboards/panel-types/value/)

## Table

Displays data in a grid with multiple dimensions. Use it when you need to scan across several group-by fields at once — for example, error count by service and status code. Supports column unit formatting.

→ [Table reference](https://signoz.io/docs/dashboards/panel-types/table/)

## Pie Chart

Shows each category as a slice of the whole. Use it when relative proportions matter more than individual values — for example, traffic share by service or error breakdown by type.

→ [Pie Chart reference](https://signoz.io/docs/dashboards/panel-types/pie/)

## List

Displays raw log lines or spans in a scrollable list. Use it when you want to surface live records directly in the dashboard — for example, the latest error logs from a service. Supports infinite scroll and search.

→ [List reference](https://signoz.io/docs/dashboards/panel-types/list/)
