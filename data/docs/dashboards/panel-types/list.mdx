## List Chart

A List panel renders raw log or trace rows as a scrollable, paginated table. A typical use case is to show error logs or recent spans alongside your charts in a single dashboard.

### Data Formats

#### Supported signals

- Logs
- Traces

This panel type shows log lines and spans in a list. Metrics are not supported as a datasource.

### Row interactions

- **Logs** — Click a row to open the **LogDetail** drawer with the full log details. Navigate to the previous or next row, and add fields to your query directly from the drawer.
- **Traces** — Click a row to open the trace detail page. Use Cmd/Ctrl+click to open the trace in a new tab.

### Pagination

List panels paginate server-side. A pagination bar below the table provides **Previous** and **Next** buttons, a current-page indicator, and a page-size picker.

### Configuration

#### Columns

Configure the displayed columns in the **Columns** editor below the query builder in the [panel editor](https://signoz.io/docs/dashboards/panel-editor/). Chosen columns appear as draggable chips:

- **Reorder** — Drag a chip to change column order.
- **Remove** — Select the × on a chip.
- **Add** — Use the searchable field-key dropdown, scoped to the panel's signal (logs or traces). You can also type a non-indexed field name verbatim.

Switching the datasource between **Logs** and **Traces** automatically resets the column selection to that signal's default field set.

Resize a column by dragging its header edge. Column widths persist across page reloads, keyed per panel.
