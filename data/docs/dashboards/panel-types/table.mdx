## Table

A Table renders scalar query results — from metrics, logs, or traces — as a sortable, paginated table. 

### Data Formats

#### Supported signals

- Logs
- Traces
- Metrics

This panel type supports any time series data. The time series data can be from logs, traces, or metrics.

### Working with the table

- **Sort** — Click a column header to sort by that column.
- **Resize columns** — Drag a column edge to resize it. Column widths persist across page reloads.
- **Search** — A search box in the panel header filters the visible rows on the current page (client-side).
- **Download** — Export the table data from the panel's three-dot actions menu.

#### Visualization

- **Panel Time Preference** — Override the global dashboard time range for this panel. Set to `Global Time` to use the dashboard's time picker, or choose a fixed time range.

#### Formatting & Units

- **Decimal Precision** — Number of decimal places to display. The default is `2 decimals`.
- **Column Units** — Set the unit for each column (for example, query `A`) to format values in human-readable format (for example, `Bytes`, `Percent`, `Milliseconds`).

#### Context Links

Add context links to enable click-through navigation from the panel to other dashboards, external URLs, or filtered views. See [Interactivity](https://signoz.io/docs/dashboards/interactivity/) for details.

#### Thresholds

Thresholds colorize table cells when a value crosses a configured limit. Each threshold has a value, color, and a target column. Choose whether the threshold changes the cell **text color** or **background color**.
