## Timeseries Chart

A Timeseries chart is a plot chart that shows trends over time. For example, you can show the memory usage over time, the number of requests over time, etc.

### Data Formats

#### Supported signals

- Logs
- Traces
- Metrics

This panel type supports any time series data. The time series data can be from logs, traces, or metrics.

#### Visualization

- **Panel Time Preference** — Override the global dashboard time range for this panel. Set to `Global Time` to use the dashboard's time picker, or choose a fixed time range.
- **Fill Gaps** — The `Fill Gaps` option fills the gaps in the result data with zero. This is useful when you want to interpret the no data as zero. It is more appropriate for when the data is sparse. For example, if the result of a query for 10 minutes is `{t1: 12, t3: 21, t5: 42, t7:29}`, the `Fill Gaps` option will result in `{t1: 12, t2: 0, t3: 21, t4: 0, t5: 42, t6: 0, t7: 29, t8: 0, t9: 0, t10: 0}`.

#### Chart appearance

Chart appearance options are illustrated tile pickers. Each tile shows a small sketch of the result, and the tiles reflow to fit the width of the config pane.

- **Line style**: `Solid` or `Dashed`.
- **How points connect**: How the line joins one point to the next. `Straight` (formerly "Linear") draws straight segments between points, `Smooth` (formerly "Spline") draws a smoothed curve, and `Step before` / `Step after` draw a stepped line.
- **Area under the line**: Fill the area beneath the line. Pick `None` for a plain line, a flat `Solid` fill, or a `Gradient` fill that fades out. When you choose `Solid` or `Gradient`, a **Fill opacity** slider appears inside this tile to control how strong the fill is.
- **Show points**: Draw a marker at each individual data point in addition to the line. Off by default.

#### Disconnect values

Use **Disconnect values** to decide how the line handles gaps in a series, meaning intervals that have no data point:

- **Connect the line** (formerly "Never"): Connect the line across every gap so the series stays continuous. This is the default.
- **Break long gaps** (formerly "Threshold"): Disconnect the line when a gap is longer than a duration you set, which keeps genuine outages visible instead of drawing a line over them.

When you switch to **Break long gaps**, a **Break when a gap is longer than** input appears. It is seeded from the query's step interval rather than a fixed default, so it reflects the resolution the panel actually queries at. The input accepts durations in seconds (`s`), minutes (`m`), hours (`h`), days (`d`), and weeks (`w`), including compound values such as `1h30m`. It validates as you type and shows an error inline.

<Admonition type="warning">
A panel saved with **Break long gaps** on and no (or a zero) gap length fails validation. Dashboards saved before this validation was added can hit it on save or load. Open the affected time series panels, set **Break when a gap is longer than** to a positive duration (for example `5m`), and save to migrate them.
</Admonition>

#### Formatting & Units

- **Y Axis Unit** — The unit of the y-axis (for example, `Milliseconds (ms)`, `Bytes`, `Percent`). The default is `None`.
- **Decimal precision** — Choose how many decimals to show from compact tiles: `0`, `1`, `2`, `3`, `4`, or `Full` (the raw value, unrounded). A live **Shows as** preview beneath the tiles displays a sample value (for example `1,234.5`) formatted at the selected precision, so you can see the effect before you save. The default is `2`.

<Admonition type="info">
When you create a new panel, the **Y Axis Unit** is pre-filled with the unit of the selected metric, so the axis matches how the metric was reported. If you choose a unit that is incompatible with the unit the metric was sent with, a warning icon appears on the unit selector. Hover the icon to see a tooltip explaining the mismatch and the unit the metric was sent with.
</Admonition>

#### Axes

- **Y-axis range** — Set the y-axis minimum and maximum in a single inline range field. Leave either side empty to let that bound auto-fit the data. This replaces the separate **Soft min** and **Soft max** fields. If you enter a minimum that is greater than the maximum, an error callout appears inline and the panel keeps the last valid range until you correct it.
- **Y Axis Scale** — Choose between `Linear` and `Logarithmic` scale for the y-axis.

#### Legend

- **Position** — Pick where the legend sits from a tile picker: **Below chart** (formerly "Bottom") or **Right of chart** (formerly "Right").
- **Legend Colors** — Customize colors for individual series in the legend. Until you run the query, this shows "Run the query to set a color for each series".

#### Alerts

Link existing alert rules to this panel or create new alerts directly from the panel configuration.

#### Context Links

Add context links to enable click-through navigation from the panel to other dashboards, external URLs, or filtered views. See [Interactivity](https://signoz.io/docs/dashboards/interactivity/) for details.

#### Thresholds

Thresholds draw a marker on the panel to highlight a value. Each saved threshold appears as a summary row that states the rule at a glance, for example `> 500 ms · Red background`.

Select **Add threshold** to open the threshold editor. It is titled **New threshold** when you add one and **Edit threshold** when you modify an existing threshold, and it offers:

- **Operator** — Pick the comparison (above, below, equal, and so on) from compact tiles that show the math symbol (`>`, `<`, `=`, and so on).
- **Value** and **Unit** — Set side by side in one row. The unit list matches the panel's units, and a mismatch with the panel unit shows a warning.
- **Color** — Choose from a row of color swatches, or use the custom-color swatch at the end to enter any color.
- **Apply color to** — A tile picker for how the color is used: `Background` or `Text`. A live preview on a sample number updates as you choose.

Select **Save** to keep the threshold, or **Cancel** (formerly "Discard") to drop your edits and return to the list.

Threshold edits stream into the panel preview as you type, so you see the effect on your data before you save. Thresholds are preserved when you change the panel's visualization type (for example, from Time Series to Table): their color, value, and unit carry over and are remapped to the new panel type's format.

Thresholds also seed the condition when you [create an alert from the panel](https://signoz.io/docs/dashboards/interactivity/#operator-and-value-from-thresholds).
