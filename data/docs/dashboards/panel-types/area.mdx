## Area Chart

An Area chart is a line chart with the region below the line filled in. It shows trends over time like a Time Series chart. When you stack series, the filled areas show how much each series adds to the total.

<Admonition type="info">
Available in SigNoz v0.143.0 and later.
</Admonition>

### Data Formats

#### Supported signals

- Logs
- Traces
- Metrics

This panel type supports any time series data from logs, traces, or metrics. Build the query with the Query Builder, ClickHouse SQL, or PromQL.

### Add an Area Chart panel

1. Open a dashboard, click **New Panel**, and select **Area Chart**.
2. Add a query and click **Run Query**. The panel draws a filled area below each series.
3. Click **Save changes**.

### Configuration

#### Visualization

- **Panel time preference**: Override the global dashboard time range for this panel. Set it to `Global Time` to use the time picker of the dashboard, or choose a fixed time range.
- **Stack series**: Choose how series combine. The default for a new panel is **Normal**.
  - **None**: Draw each series on its own. Series overlap where their values are close.
  - **Normal**: Draw each series on top of the one below it, so the top edge shows the total.
  - **Percent**: Rescale each time column so all series together total 100%. See [Percent stacking](#percent-stacking).
- **Fill gaps**: Fill gaps in the result data with zero. Use it when missing data means zero, which is common for sparse data. For example, if the result of a query for 10 minutes is `{t1: 12, t3: 21, t5: 42, t7: 29}`, **Fill gaps** produces `{t1: 12, t2: 0, t3: 21, t4: 0, t5: 42, t6: 0, t7: 29, t8: 0, t9: 0, t10: 0}`.

#### Formatting & Units

- **Unit**: The unit of the y-axis, for example `Milliseconds (ms)`, `Bytes`, or `Percent`. The default is `None`.
- **Decimals**: The number of decimal places to display. The default is `2 decimals`.

<Admonition type="info">
When you create a new panel, **Unit** is pre-filled with the unit of the selected metric. If you choose a unit that does not match the unit of the metric, a warning icon appears on the unit selector. Hover over the icon to see the unit the metric was sent with.
</Admonition>

#### Axes

- **Soft min** and **Soft max**: Set the y-axis range. When you set them, the y-axis uses these values instead of the range of the data.
- **Y-axis scale**: Choose `Linear` or `Log`.

#### Legend

- **Position**: Show the legend at the `Bottom` or on the `Right`.
- **Series colors**: Set the color of each series.

#### Chart appearance

- **Line style**: `Solid` or `Dashed`.
- **Line interpolation**: `Linear`, `Spline` (a smoothed curve), `Step before`, or `Step after`.
- **Fill mode**: `Solid` for a flat fill under the line, or `Gradient` for a fill that fades out. An Area Chart is always filled, so it has no `None` option.
- **Fill opacity**: Set the transparency of the fill from 0% to 100%. The default is 44%. Lower values make overlapping series easier to read when **Stack series** is **None**.
- **Show points**: Draw a marker at each data point. Off by default.
- **Disconnect values**: Choose how the line handles intervals that have no data point.
  - **Never**: Connect the line across every gap. This is the default.
  - **Threshold**: Break the line when a gap is longer than the **Threshold value**. The value cannot be shorter than the step interval of the query. It accepts durations in seconds (`s`), minutes (`m`), hours (`h`), days (`d`), and weeks (`w`), including compound values such as `1h30m`.

#### Thresholds

Thresholds draw a line on the y-axis to highlight a value. Threshold edits preview live as you type, and thresholds carry over when you change the panel type. See [Panel editor behavior](https://signoz.io/docs/userguide/manage-dashboards/#panel-editor-behavior). Thresholds also set the condition when you [create an alert from the panel](https://signoz.io/docs/dashboards/interactivity/#operator-and-value-from-thresholds).

#### Context Links

Add context links to open other dashboards, external URLs, or filtered views from the panel. See [Interactivity](https://signoz.io/docs/dashboards/interactivity/) for details.

### Percent stacking

Set **Stack series** to **Percent** to compare the share of each series in the total over time. Each time column is rescaled so all series together add up to 100%. The y-axis shows percentage labels and stops at 100%.

The tooltip shows the raw value of each series, not its stacked or rescaled value. This applies to **Normal** and **Percent** stacking.

<Figure
  src="/img/docs/dashboards/panel-types/area-percent-tooltip.webp"

  caption="Percent stacking. The tooltip shows the raw value of each series."

Only the Area Chart panel offers percent stacking. The Bar Chart panel has an on and off stacking switch.

### Switch panel type

The stacking setting carries over when you switch between Area Chart and [Bar Chart](https://signoz.io/docs/dashboards/panel-types/bar/):

- Area Chart **None** becomes Bar Chart stacking off. **Normal** and **Percent** become stacking on.
- Bar Chart stacking on becomes Area Chart **Normal**. Stacking off becomes **None**.

### Panel actions

Area Chart panels support view, edit, clone, drilldown, create alert, and download as PNG or SVG. CSV download is not available.
