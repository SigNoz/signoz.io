## What dashboards are in SigNoz

Dashboards in SigNoz let you build custom visualizations over any telemetry signal — metrics, logs, or traces — and combine them into a single view for your team. Use pre-built templates to get started instantly, or compose panels from scratch.

## Key capabilities

- **Drag-and-drop panels**: Add, resize, and rearrange visualization panels without writing any configuration code.
- **Dynamic variables**: Define template variables to make dashboards interactive — filter by environment, service, host, or any attribute without duplicating dashboards.
- **Terraform automation**: Manage dashboards as code using the [SigNoz Terraform provider](https://signoz.io/docs/dashboards/terraform-provider-signoz/) for repeatable, version-controlled deployments.
- **60+ pre-built templates**: Import community-maintained dashboard templates for popular integrations and skip setup entirely.

## Key product capabilities

### Panels

SigNoz supports seven panel types to match your data and use case:

- **Time series** — plot metrics or log counts over time; the default for trend analysis
- **Value** — display a single aggregated number, ideal for KPIs and SLO summaries
- **Table** — show multi-column query results with sortable rows
- **Bar chart** — compare values across discrete categories
- **Histogram** — visualize the distribution of a metric (e.g., latency buckets)
- **Pie chart** — show proportional breakdowns across a small set of groups
- **List** — display raw log lines or trace spans inline in a dashboard

### Variables

Variables make dashboards reusable across services and environments:

- **Query variables** — populate dropdown options dynamically from a metric, log, or trace query
- **Custom variables** — define a static list of values (e.g., `production`, `staging`)
- **Textbox variables** — accept free-form user input for flexible filtering
- **Dynamic filtering** — variables propagate to all panels automatically when a selection changes
