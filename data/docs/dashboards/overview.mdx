Dashboards in SigNoz let you build custom views that combine metrics, traces, and logs. Create panels with the Query Builder, arrange them freely, filter with variables, and share them publicly.

## What you can do

- Build dashboards with panels for metrics, traces, and logs
- Choose from seven [panel types](https://signoz.io/docs/dashboards/panel-types/): Timeseries, Bar, Histogram, Value, Table, Pie, and List
- Use variables to filter all panels at once across services, environments, or hosts
- Drill into raw signals from any panel with one click using [Interactivity](https://signoz.io/docs/dashboards/interactivity/)
- Import [pre-built templates](https://signoz.io/docs/dashboards/dashboard-templates/overview/) for popular services and infrastructure
- Share dashboards publicly with a read-only link
- Manage dashboards as code with the [Terraform provider](https://signoz.io/docs/dashboards/terraform-provider-signoz/)

## Where to find it

Go to **Dashboards** in the SigNoz sidebar.
