This dashboard charts the NGINX metrics that the OpenTelemetry Collector's `nginx` receiver scrapes from the `stub_status` page: request volume, accepted and handled connections, and current connections by state.

<Admonition type="info">
To populate this dashboard, send NGINX metrics to SigNoz first. Follow the [NGINX metrics](https://signoz.io/docs/metrics-management/nginx-metrics/) guide.
</Admonition>

## What This Dashboard Monitors

- **Request volume**: How many requests NGINX serves over the selected time range.
- **Connection handling**: Whether NGINX handles every connection it accepts. A gap between accepted and handled connections points to a resource limit such as `worker_connections`.
- **Connection states**: How many connections are active, reading, writing, or waiting (idle keep-alive).

Use the `host.name` and `service.name` variables at the top of the dashboard to filter by NGINX host or service.

## Metrics Included

### Value panels

| Panel | Metric | Shows |
| --- | --- | --- |
| Total requests | `nginx.requests` | Requests served in the selected time range |
| Accepted connections | `nginx.connections_accepted` | Connections accepted in the selected time range |
| Handled connections | `nginx.connections_handled` | Connections handled in the selected time range |
| Active | `nginx.connections_current` (`state = active`) | Latest count of active connections |
| Writing | `nginx.connections_current` (`state = writing`) | Latest count of connections writing a response |
| Waiting | `nginx.connections_current` (`state = waiting`) | Latest count of idle keep-alive connections |

### Time series panels

| Panel | Metric | Shows |
| --- | --- | --- |
| Requests | `nginx.requests` | Requests per interval |
| Accepted conns | `nginx.connections_accepted` | Accepted connections per interval |
| Handled conns | `nginx.connections_handled` | Handled connections per interval |
| Current conns | `nginx.connections_current` | Connections over time, one series per `state` |
