Use SigNoz alerts to define conditions on your metrics, logs, and traces data, and get notified when those conditions are met. Alerts help you detect and respond to issues before they affect your users.

## What you can do with Alerts

- Create threshold-based alerts on metrics, logs, traces, or exceptions
- Detect anomalies automatically using historical patterns and seasonality
- Route alert notifications to Slack, PagerDuty, MS Teams, email, and more
- Suppress alerts during planned maintenance windows
- Analyze alert history to understand frequency, resolution time, and top contributors
- Manage alerts as code using the Terraform provider

## Where to find it

Go to **Alerts** in the left navigation menu in SigNoz.

## Alert types

| Alert type | Use when |
|---|---|
| [Metrics-based](https://signoz.io/docs/alerts-management/metrics-based-alerts/) | Monitor numeric metrics: CPU, memory, error rates, latency |
| [Log-based](https://signoz.io/docs/alerts-management/log-based-alerts/) | Alert on log patterns, keywords, or aggregated log counts |
| [Trace-based](https://signoz.io/docs/alerts-management/trace-based-alerts/) | Alert on span attributes, latency percentiles, or trace error rates |
| [Exceptions-based](https://signoz.io/docs/alerts-management/exceptions-based-alerts/) | Alert when specific application exceptions are detected |
| [Anomaly detection](https://signoz.io/docs/alerts-management/anomaly-based-alerts/) | Alert when a metric deviates from its historical seasonal pattern |

## How alerts work

Every alert has three parts:

1. **Query** — defines what data to evaluate using the Query Builder (metrics, logs, traces) or a ClickHouse SQL query
2. **Conditions** — defines when to fire: threshold value, match type (at least once, all the time, on average, in total, last), and evaluation window
3. **Configuration** — sets severity, name, description, labels, and which notification channels to use

SigNoz evaluates each alert on a configurable frequency (default: every 1 minute). When the condition is met for the specified window, notifications are dispatched to the configured channels.
