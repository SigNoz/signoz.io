[AI Observability](https://signoz.io/docs/ai-observability/) reads these attributes from your spans. A panel stays empty until your spans carry the attributes that it uses. Most names come from the <a href="https://opentelemetry.io/docs/specs/semconv/gen-ai/" target="_blank" rel="noopener noreferrer nofollow">OpenTelemetry GenAI semantic conventions</a>. If your instrumentation uses other names, map them in [Attribute Mapping](https://signoz.io/docs/ai-observability-attribute-mapping/).

## Span attributes

| Attribute | Used by |
| --- | --- |
| `gen_ai.request.model` | All LLM panels and the **model** filter. SigNoz counts a span with this attribute as an LLM call. |
| `gen_ai.provider.name` | **Cost by provider** and the **provider** filter. |
| `gen_ai.usage.input_tokens`, `gen_ai.usage.output_tokens` | Token panels and cost. |
| `gen_ai.usage.cache_read.input_tokens`, `gen_ai.usage.cache_creation.input_tokens` | Cache token panels, cache cost, and **Prompt cache hit ratio**. |
| `gen_ai.server.ttft` | **TTFT (p95)** and **Time to first token**. Streaming instrumentations, such as OpenLIT, send this attribute in seconds. |
| `gen_ai.response.finish_reasons` | **Finish reasons** panel. Also sets the finish reason on every output message in the [conversation thread](https://signoz.io/docs/ai-observability-conversation-thread/), overriding per-message values. |
| `gen_ai.tool.name` | All **Tool calls** panels. SigNoz counts a span with this attribute as a tool call. |
| `gen_ai.agent.name` | Agent spans for the **Per-trace usage** panels. |

An AI trace is a trace with at least one LLM, tool, or agent span. Error panels use the error status of the span, not an attribute.

## Conversation thread attributes

The [conversation thread](https://signoz.io/docs/ai-observability-conversation-thread/) in [Trace Details](https://signoz.io/docs/userguide/span-details/) reads these attributes from an LLM or agent span. They carry prompt and response content, which is **Opt-In** in the OpenTelemetry specification, so SigNoz only renders a turn when the span carries the matching attribute.

| Attribute | Used by |
| --- | --- |
| `gen_ai.system_instructions` | The leading **system** message in the conversation thread. |
| `gen_ai.input.messages` | The user and prior turns in the conversation thread. |
| `gen_ai.output.messages` | The assistant turns and tool calls in the conversation thread. |

## Resource attributes

| Attribute | Used by |
| --- | --- |
| `deployment.environment` | The **environment** filter. |
| `service.name` | The **service_name** filter and **Cost by service**. |

Tool spans do not carry a model. As a result, the **model** and **provider** filters do not affect the **Tool calls** panels or **Calls per AI trace**.
