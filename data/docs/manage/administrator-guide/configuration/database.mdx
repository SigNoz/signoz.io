SigNoz ships with SQLite by default for quick setups. For production and larger deployments, you can configure SigNoz to use a relational database.


## Supported databases

- SQLite (default; great for quick setups and small deployments)
- PostgreSQL (recommended for production)
- More relational databases are planned. Follow our [changelog](https://signoz.io/changelog) and [Github Ticket #7316](https://github.com/SigNoz/signoz/issues/7316) for updates.

## Configure a Relational Database

All relational database providers use the environment variable `SIGNOZ_SQLSTORE_PROVIDER` (check the [configuration options](/docs/operate/configuration#environment-variables) for more details) 
to select the backend.

### PostgreSQL

To use PostgreSQL, set the following environment variables on the `signoz` service:

```bash
SIGNOZ_SQLSTORE_PROVIDER: postgres
SIGNOZ_SQLSTORE_POSTGRES_DSN: postgres://signoz:your_password@postgres:5432/signoz?sslmode=disable
```

- On first startup with PostgreSQL, SigNoz runs automatic schema migrations. This may take some time depending on database size and latency.
- Ensure the specified database already exists and the user has privileges to create and migrate tables.
- For more background on PostgreSQL support, see our [OSS improvements](https://signoz.io/blog/oss-improvements).
