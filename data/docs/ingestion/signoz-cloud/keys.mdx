<Admonition type="info">
Ingestion keys apply to SigNoz Cloud and Self-Hosted Enterprise. The Community Edition of Self-Hosted SigNoz does not need them.
</Admonition>

## Overview

Ingestion keys are tokens that authenticate the telemetry you send to SigNoz. Each key is unique to your account. Keep your keys private.

Ingestion keys are **write-only**. They can only send telemetry data (traces, logs, metrics) into your account. You cannot use them to query, read, or delete data. **API keys** are different: they can query and read data from your account, so never put them in client-side code.

You can also do every ingestion key and limit operation on this page through the <a href="https://signoz.io/api-reference/#/operations/CreateIngestionKey" target="_blank" rel="noopener noreferrer nofollow">SigNoz API</a>.

## Using Ingestion Keys in Frontend/Browser Applications

Because ingestion keys are write-only, you can use them in frontend applications, where anyone can see the key in browser code. If someone copies the key, they can send unwanted telemetry to your account. This raises your ingestion volume and your costs.

To limit this risk, create a dedicated ingestion key for frontend use with the following safeguards:

- **Ingestion limits**: Set daily and per-second caps per signal type (see [Add Limits to a Key](#add-limits-to-a-key)) to cap the cost of misuse.
- **Expiration date**: Set an expiration date so the key stops working after that date.

<Admonition type="warning">
API keys allow querying and reading data from your account. Never expose API keys in frontend or client-side code.
</Admonition>

## Prerequisites

- A [SigNoz Cloud](https://signoz.io/teams/) or Self-Hosted Enterprise account with Editor or Admin access

## Add an Ingestion Key
To add a SigNoz Ingestion key:

1. Go to **Settings > Identity & Access > Ingestion**.
2. Click the **New Ingestion Key** button.
3. Enter a name for your key. Use at least 6 characters: letters, numbers, underscores, or hyphens.
4. Set an expiration date for the key.
5. (**Optional**) Add tags to categorize or organize your key.
6. Click **Create new Ingestion key**.

Only Editors and Admins can manage ingestion keys. An account can have up to 50 ingestion keys, and each key name must be unique.

## Modify Ingestion Keys
To modify an existing SigNoz Ingestion key, go to **Settings > Identity & Access > Ingestion** and click the edit icon next to the key. You can change only the expiry date and tags.

## Remove Ingestion Keys
To remove a SigNoz Ingestion key, go to **Settings > Identity & Access > Ingestion**, click the Trash icon next to the key, and confirm. You need the Editor or Admin role. SigNoz revokes the key at once, and you cannot undo this.

## Add Limits to a Key
To add a limit to an existing key:

1. Go to **Settings > Identity & Access > Ingestion**.
2. Click the arrow at the left of the key to expand it.
3. In the **LIMITS** section, click **+ Limits** next to the signal (logs, traces, or metrics).
4. Turn on **Daily limit**, **Per Second limit**, or both, and enter the values.
5. Click **Save**.

Limits apply per key and per signal. SigNoz Cloud has no limit for the whole workspace and no limit in dollars. To get an alert when your spend reaches a dollar amount, set up a [Cost Meter alert](https://signoz.io/docs/cost-meter/alert-configuration-guide/).

<Figure

<Admonition type="warning">
When a key reaches its limit for a signal, SigNoz drops new data for that signal until the limit resets, which leaves gaps in your data. To get a warning before a key reaches its daily limit, set up a [Meter Alert](https://signoz.io/docs/cost-meter/alerts/).
</Admonition>

If you're missing data entirely rather than seeing gaps, see [Debug missing traces, logs, and metrics in SigNoz](https://signoz.io/docs/ingestion/signoz-cloud/troubleshooting/data-not-appearing/) to narrow down the cause.

## Modify a Limit
To modify a limit, expand the key and click the edit icon next to the limit. Changing a limit does not reset the usage counted so far. For example, if you used 15 GB of a 20 GB/day limit and raise it to 25 GB/day, the count continues from 15 GB.

## Remove a Limit
To remove a limit, expand the key and click the delete icon next to the limit. Deleting a limit resets the usage count to 0. For example, if you used 15 GB of a 20 GB/day limit and delete it, the count goes back to 0, and any new limit starts from 0.

## Filter Logs and Traces by Ingestion Key

You can filter logs and traces by ingestion key to see only the data sent with that key. Use this to:
- Find which integration or source sends the data.
- Troubleshoot ingestion from one environment or service.
- Compare usage across ingestion keys.

### View Logs by Ingestion Key

To filter logs by a specific ingestion key:

1. Go to **Logs**.
2. In the filter section, add a filter for `signoz.workspace.key.id`.
3. Set the operator to `IN` or `=`.
4. Enter the ingestion key ID as the value.
5. Apply the filter to see the logs sent with that key.

### View Traces by Ingestion Key

To filter traces by a specific ingestion key:

1. Go to **Traces**.
2. In the filter section, add a filter for `signoz.workspace.key.id`.
3. Set the operator to `IN` or `=`.
4. Enter the ingestion key ID as the value.
5. Apply the filter to see the traces sent with that key.

### Finding Your Ingestion Key ID

To find the ID of a specific ingestion key:

1. Go to **Settings > Identity & Access > Ingestion**.
2. Click the arrow at the left of the key to expand it.
3. Copy the value in the **ID** row.
