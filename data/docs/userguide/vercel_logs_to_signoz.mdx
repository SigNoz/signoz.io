If you are running your applications on [Vercel](https://vercel.com/), you can stream logs from Vercel to SigNoz using [log drains](https://vercel.com/docs/drains).

## Prerequisites

- Vercel Pro or Enterprise accounts
- An instance of [SigNoz Cloud](https://signoz.io/teams/)

## Configure Vercel Log Drains

Follow the steps below to send your logs from Vercel to SigNoz Cloud:

### Step 1: Open the Vercel Dashboard

Navigate to **Team Settings** > **Drains** and click **Add Drain**.

### Step 2: Choose Data Type

Select the type of observability data you want to drain. In this case, choose **Logs**.

### Step 3: Configure the Drain

Provide a name for your drain, select which projects should send data to your endpoint, and configure the log source, environment, and sampling rate.

<Figure
  src="/img/logs/vercel/sources.webp"
  caption="Vercel Drain Sources, and Environment"
  alt="Vercel Drain Sources, and Environment"
/>

### Step 4: Set the Endpoint URL

Use the following endpoint format:

- `https://ingest.<region>.signoz.cloud:443/logs/json`
- `<region>`: Your [SigNoz Cloud region](https://signoz.io/docs/ingestion/signoz-cloud/overview/#endpoint)

### Step 5: Configure Destination

Choose how you want to receive your drain data. Under the **Custom Endpoint** tab, set the delivery format to `JSON`.

### Step 6: Add Custom Headers

Enable **Custom Headers** and add the following headers:

- `signoz-ingestion-key`: Use the ingestion key from your SigNoz Cloud instance for data authentication.

<Figure
  src="/img/logs/vercel/headers.webp"
  caption="Vercel Custom Headers"
  alt="Vercel Custom Headers"
/>

### Step 7: Test the Log Drain

Click on **Test** to ensure your endpoint receives the data correctly. If successful, you will start to see sample logs on the SigNoz UI.

<Figure
  src="/img/logs/vercel/sample-logs.webp"
  caption="Sample Logs"
  alt="Sample Logs"
/>

<Admonition type="note">
  It might take some time for the logs to appear.
</Admonition>

### Step 8: Create the Drain

After checking your configuration and successfully testing, click **Create Drain** in your Vercel dashboard.

Your Vercel logs will now be streamed to SigNoz Cloud.
