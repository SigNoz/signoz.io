Dashboards in SigNoz let you build custom views combining metrics, traces, and logs. This page covers creating, editing, and deleting dashboards, managing their layout, and enabling public sharing.

## Create a dashboard

1. From the sidebar, choose **Dashboards**.
2. Select **+ New Dashboard**.
3. Select the **Edit** button (top right), then enter:
   - **Name** — a descriptive name for the dashboard.
   - _(Optional)_ **Tags** — select **New Tag** to add one or more tags.
   - _(Optional)_ **Description** — a brief summary of what the dashboard monitors.
4. Select **Save**.
5. Add panels by following the steps in [Add Panels](https://signoz.io/docs/userguide/manage-panels/).
6. _(Optional)_ Drag and drop panels to rearrange them.
7. Select **Save Layout** when done.

<Admonition type="tip">

SigNoz provides ready-to-use dashboard JSON files for common services. See [Dashboard Templates](https://signoz.io/docs/dashboards/dashboard-templates/overview/) or [Import a Dashboard](https://signoz.io/docs/dashboards/import-dashboard/) to get started quickly.

</Admonition>

## Edit a dashboard

**To rename, retag, or update the description:**

1. Select the **Edit** button (top right).
2. Make your changes.
3. Select **Save Layout**.

**To resize a panel:**

1. Click and hold the bottom-left corner of the panel.
2. Drag to resize.
3. Select **Save Layout**.

**To reorder panels:**

1. Drag a panel to its new position.
2. Select **Save Layout**.

## Delete a dashboard

1. From the sidebar, choose **Dashboards**.
2. Find the dashboard in the list. In the **Action** column, select **Delete**.

## Share a dashboard publicly

Public sharing generates a read-only link that anyone can view without a SigNoz login.

**To enable public sharing:**

1. Open the dashboard you want to share.
2. Click the **Configure** icon to open the configuration drawer.
3. Select **Publish**.
4. _(Optional)_ Toggle **Enable time range** to let viewers change the time range. If disabled, the dashboard is fixed to the **Default time range** you set.
5. Select **Publish Dashboard**. A shareable link is generated.

<Admonition type="info">

If the time range option is disabled, viewers see only the data for the specified default time range and cannot adjust it.

</Admonition>

**To disable public sharing:**

1. Open the dashboard.
2. Click the **Configure** icon.
3. Select **Publish**, then click **Revoke**.
