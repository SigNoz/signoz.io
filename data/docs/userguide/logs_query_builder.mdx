The Logs Explorer in SigNoz provides a powerful interface for searching, filtering, and analyzing your log data. It includes quick filters on the left panel, a filter expression bar, and three view modes — List View, Time Series, and Table.

## Key Features

### Filtering and Search

Write filter expressions in the search bar to narrow your logs. The query field supports auto-suggestions for both attributes and values. Use operators like `=`, `!=`, `IN`, `NOT IN`, `CONTAINS`, `EXISTS`, and combine them with `AND`/`OR`.

After entering your query, click **Run Query** to see results in the selected view mode.

    <img src="/img/docs/logs-management/ui/logs-list-view.webp" alt="Logs list view with filter applied"/>
    <figcaption><i>List view showing filtered logs with timestamp and body columns</i></figcaption>
</figure>

### Log Details

Click on any log line to open the **Log details** panel. This shows the full log body, attributes, and resource fields in a structured view. The detail panel has four tabs — Overview, JSON, Context, and Metrics.

From the attribute values in the detail panel, you can:
- **Filter for value** — add the attribute as an `IN` filter
- **Filter out value** — add the attribute as a `NOT IN` filter
- **Group By Attribute** — add the attribute to Group By
- **Replace filters with this value** — replace the current filter with this specific value

<figure data-zoomable align='center'>
    <img src="/img/docs/logs-management/ui/logs-detail-view.webp" alt="Log details panel with attribute actions"/>

### Aggregation and Group By

Switch to the **Time Series** view to see log counts over time. Use the **Group By** dropdown to break down results by attributes like `service.name`, `k8s.pod.name`, or any custom attribute.

The query builder supports:
- **Aggregate functions**: `count()`, `count_distinct()`, `avg()`, `sum()`, `p50()`, `p90()`, `p95()`, `p99()`
- **Group By**: Split results by one or more attributes
- **Having / Order By / Limit / Legend format**: Refine and customize the output

### Filter by Value

In the log details panel, hover over any attribute value to see quick action icons. These let you instantly filter for or against a value, group by the attribute, or replace the current filters — all without manually editing the query.

<figure data-zoomable align='center'>
    <img src="/img/docs/logs-management/ui/logs-filter-by-value.webp" alt="Filter by value options on attribute"/>
    <figcaption><i>Quick actions on attribute values: Filter for value, Filter out value, Group By Attribute, Replace filters</i></figcaption>
</figure>

### Create Dashboards and Alerts

At the bottom of the Logs Explorer, you can:
- **Save this view** — preserve your query configuration for quick access later
- **Create an Alert** — set up a log-based alert directly from your current query
- **Add to Dashboard** — export the current query as a dashboard panel

<figure data-zoomable align='center'>
    <img src="/img/docs/logs-management/ui/logs-create-dashboard-alert.webp" alt="Create dashboard and alert from logs explorer"/>
    <figcaption><i>Save view, create alert, or add to dashboard directly from the Logs Explorer</i></figcaption>

### Multiple Queries and Formulas

You can plot multiple queries and formulas on the same chart. This is useful for comparing log volumes across different services or calculating rates like error percentages.
