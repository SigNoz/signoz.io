Panels are the building blocks of a dashboard. Each panel queries a signal (metrics, traces, or logs) and renders it in a chosen [panel type](https://signoz.io/docs/dashboards/panel-types/).

## Add a panel

1. From the sidebar, choose **Dashboards** and open the dashboard where you want to add a panel.
2. Select **Add Panel**.
3. Choose a [panel type](https://signoz.io/docs/dashboards/panel-types/) — **Timeseries**, **Bar**, **Histogram**, **Value**, **Table**, **Pie**, or **List**.
4. Enter:
   - **Panel Title** — a descriptive name.
   - **Description** — a brief summary of what the panel shows.
   - _(Optional)_ **Panel Time Preference** — overrides the global dashboard time range for this panel only.
   - _(Optional)_ **Y Axis Unit** — unit label for the y-axis (where applicable).
5. Write your query using one of:
   - **Query Builder** — graphical interface. See [Query Builder](https://signoz.io/docs/userguide/query-builder-v5/).
   - **ClickHouse SQL** — for advanced queries. See the [ClickHouse SQL Reference](https://clickhouse.com/docs/en/sql-reference/).
   - **PromQL** — for Prometheus-style queries. See [Prometheus Querying Language](https://prometheus.io/docs/prometheus/latest/querying/basics/).
6. _(Optional)_ Apply mathematical functions to transform query results (exp, log, sqrt, sin, cos, etc.).
7. _(Optional)_ Add up to 10 queries on the same panel using **+ Query**.
8. Select **Save** when done.

<Admonition type="info">

After adding or modifying a function or formula, select **Stage & Run Query** before saving. Unsaved changes appear as an orange dot on the affected tab.

</Admonition>

## Update a panel

1. From the sidebar, choose **Dashboards** and open the dashboard containing the panel.
2. Select the **pencil icon** at the top right of the panel.
3. Make your changes.
4. Select **Save**.
