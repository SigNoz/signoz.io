## Overview

SigNoz automatically generates RED metrics from your trace data and provides ready-made dashboard templates you can import with a single click. This guide walks through importing each template and explains what metrics it exposes.

<Admonition type="info">

- Your application is instrumented and sending trace data to SigNoz
- Services are visible in the **Services** section

</Admonition>

## Auto-generated APM metrics

Before importing dashboards, it helps to know what metrics are available. SigNoz generates the following from span data automatically:

| Metric | Description |
|---|---|
| `signoz_calls_total` | Count of all calls per service/operation, used to calculate request rate and error rate |
| `signoz_latency_sum` | Total sum of all recorded request durations |
| `signoz_latency_count` | Number of requests measured; divide into sum for average latency |
| `signoz_latency_bucket` | Histogram buckets for latency distribution (default: 2ms–15s) |
| `signoz_db_latency_sum` | Total latency for all database operations |
| `signoz_db_latency_count` | Number of database operations measured |
| `signoz_external_call_latency_sum` | Total latency for all external (outbound) calls |
| `signoz_external_call_latency_count` | Number of external calls measured |

Common dimensions on all metrics: `operation`, `service_name`, `span_kind`, `http_status_code`, `status_code`, `deployment_environment`, `service_namespace`.

See [APM Metrics reference](/docs/traces-management/guides/apm-metrics) for full detail.

## Steps

### Step 1: Import the APM Metrics dashboard

**Action:** Go to **Dashboards** in SigNoz, click **New Dashboard > Import JSON**, and paste the content from [apm-metrics.json](https://github.com/SigNoz/dashboards/blob/main/apm/apm-metrics.json).

This dashboard includes:

| Chart | What it shows |
|---|---|
| Latency | P50/P95/P99 request latency |
| Request Rate | Requests per second |
| Error Percentage | Error rate over time |
| Top Operations | Slowest operations by latency |
| DB Calls RPS | Database calls per second |
| DB Calls Avg Duration | Average database operation latency |
| Top External Calls | External services with highest call volume |

### Step 2: Import the HTTP API Monitoring dashboard

**Action:** Import [http-api-monitoring.json](https://github.com/SigNoz/dashboards/blob/main/apm/http-api-monitoring.json).

This template is built on [OTel HTTP semantic convention attributes](https://opentelemetry.io/docs/specs/semconv/attributes-registry/http/) and includes:

| Chart | What it shows |
|---|---|
| Latency (P90) per Endpoint | P90 latency broken down by API route |
| HTTP Status Code Distribution | Breakdown of 2xx, 4xx, 5xx responses |
| Top HTTP Endpoints | Highest-traffic routes |
| External HTTP APIs | Latency and error rate for external API calls |

### Step 3: Import the DB Calls Monitoring dashboard

**Action:** Import [db-calls-monitoring.json](https://github.com/SigNoz/dashboards/blob/main/apm/db-calls-monitoring.json).

Built on [OTel DB client call attributes](https://opentelemetry.io/docs/specs/semconv/attributes-registry/db/), this dashboard includes:

| Chart | What it shows |
|---|---|
| DB Transaction Rate | Database calls per second |
| Top DB Calls | Most frequently called queries or operations |
| Slowest DB Calls | Operations with highest average latency |
| DB Call Error Rate | Percentage of database calls resulting in errors |
