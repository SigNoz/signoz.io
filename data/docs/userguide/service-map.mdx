## What is the Service Map?

The **Service Map** renders a live dependency graph of all your instrumented services, showing which services call which and how healthy each connection is. Edges highlighted in red signal elevated error rates or high latency — giving you an immediate, visual starting point for investigation without digging through individual traces.

## What you can do with Service Map

- See which services call which, and in what direction
- Hover over any edge to view P99 latency, error rate, and requests per second for that connection
- Identify red edges — connections with 4xx errors or high latency — as the first signal of a problem

## Where to find it

Go to **Services** in the SigNoz sidebar, then select the **Service Map** tab.
