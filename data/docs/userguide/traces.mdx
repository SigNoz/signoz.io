A trace is a recording of the path a request takes through your system — from the first service it hits to every downstream call it makes. Each trace is made up of spans, where each span represents a single unit of work in one service.

## Visualize aggregate metrics from traces

SigNoz lets you create aggregates of your filtered traces using various aggregate functions. See [query builder aggregation docs](https://signoz.io/docs/userguide/query-builder/#aggregation) for details.

## Filter spans by tags and attributes

The Trace Explorer provides quick filtering of spans using various parameters.

There are two ways to filter traces:

- **Quick Filter** — select a filter from the panel on the left. More details on available quick filters are [here](https://signoz.io/docs/product-features/trace-explorer/#quick-filters).

<figure data-zoomable align='center'>
    <img src="/img/docs/product-features/trace-explorer/trace-explorer-quick-filters.webp" alt="Quick Filters in Traces Explorer"/>
    <figcaption><i>Quick Filters in Traces Explorer</i></figcaption>
</figure>

- **Query Builder** — select the **Search Filter** input, choose a key from your attributes, select an operator, and enter a value. Select **Stage and Run Query** to apply. See the [Query Builder docs](https://signoz.io/docs/userguide/query-builder/#using-the-filtering-feature) for more details.
