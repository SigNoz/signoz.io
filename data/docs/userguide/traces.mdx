## What is the Traces Explorer?

The **Traces Explorer** lets you search, filter, and visualize every distributed trace SigNoz has collected. A trace captures the full journey of a single request across your services — each unit of work is a **span**. You can aggregate spans into metrics, drill into individual traces to find bottlenecks, and jump to correlated logs.

## What you can do with Traces Explorer

- Compute aggregate metrics — rate, errors, latency percentiles — over any filtered set of spans
- Filter spans by service, tag, attribute, HTTP status, or any custom key
- Inspect individual traces in a flame graph and waterfall view
- Navigate from any trace directly to its correlated logs

## How filtering works

There are two ways to filter spans:

**Quick Filters** — select a preset filter from the sidebar panel. See [available quick filters](https://signoz.io/docs/product-features/trace-explorer/#quick-filters).

<figure data-zoomable align='center'>
    <img src="/img/docs/product-features/trace-explorer/trace-explorer-quick-filters.webp" alt="Quick Filters in Traces Explorer"/>
    <figcaption><i>Quick Filters</i></figcaption>
</figure>

**Query Builder** — select the **Search Filter** input, choose an attribute key, pick an operator, enter a value, then click **Stage and Run Query**. You can also create aggregates (sum, average, percentile) over any filtered set. See [Query Builder docs](https://signoz.io/docs/userguide/query-builder/#using-the-filtering-feature).
