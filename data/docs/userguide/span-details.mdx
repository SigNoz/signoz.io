The **Trace Details** page visualizes the complete journey of a single request through your system. It renders synchronized flame graphs and waterfall charts for traces with up to a **million spans**, and lets you inspect individual spans to diagnose latency and errors in real time.

## Opening a trace

Select any trace from the [Traces Explorer](/docs/userguide/traces). The Trace Details page opens with two synchronized views.

## Key concepts

| Term | Definition |
|---|---|
| **Trace** | The complete path a request takes through your system, from the first service to the last |
| **Span** | A single unit of work within a trace — a structured log enriched with context, hierarchy, and timing |
| **Root span** | The first span in a trace; has no Parent Span ID |
| **Span Context** | Metadata that links spans across services: trace ID, span ID, parent span ID, and flags |
| **Span Attributes** | Key-value pairs storing operation metadata (e.g., `http.method`, `db.statement`) |
| **Span Links** | References that establish causal relationships between spans, useful for async operations |
| **Span Events** | Timestamped structured log messages recorded during the span's execution |

## Views

### Flame graph

Displays spans as a hierarchical tree — wider bars indicate longer duration. Child spans appear nested under their parent. Selecting a span in the flame graph highlights it in the waterfall, and vice versa.

### Waterfall chart

Provides a timeline view showing the start time, duration, and sequence of every span. Synchronized with the flame graph at all times.

### Resizable anchor

Drag the divider between span names and the timeline to widen or narrow the name column if span names appear truncated.

## Span details panel

Click any span in the flame graph or waterfall to open its details panel.

| Field | Description |
|---|---|
| **Span Kind** | `SERVER`, `CLIENT`, `PRODUCER`, `CONSUMER`, or `INTERNAL` |
| **Span Context** | Trace ID, Span ID, Parent Span ID, and propagation flags |
| **Attributes** | All key-value metadata attached to the span |
| **Events** | Timestamped log messages recorded during the span's execution |
| **Span Links** | References to other spans, used for async or batch correlation |

### Span percentile

Each span shows its latency percentile (p50, p90, p95, p99) compared to spans from the same service over the past hour. The percentile badge may take a few seconds to appear after opening the panel.

<Figure src="/img/docs/apm-and-distributed-tracing/span-percentile.webp" alt="span-percentile" caption="Span percentile badge" />

Click the badge to see exact p50, p90, and p99 values.

<Figure src="/img/docs/apm-and-distributed-tracing/span-percentile-details.webp" alt="span-percentile-details" caption="Span percentile detail breakdown" />

Add resource attributes to narrow the comparison set, or expand the time range for a longer baseline.

## Search and filter

Use the search bar in Trace Details to filter visible spans by attribute, status, or name. Spans load dynamically as you scroll, keeping large traces navigable.

**Example — debug errors:**
1. Enable the `has_error = true` filter to highlight all error spans.
2. Click an error span to view its error message and associated events.
3. Check upstream callers to identify the root cause.
