Vercel supports automatic OpenTelemetry (OTel) trace export to SigNoz without code changes using <a href="https://vercel.com/docs/drains" target="_blank" rel="noopener noreferrer nofollow">OpenTelemetry drains</a>.

## Prerequisites

- A <a href="https://vercel.com/docs/plans" target="_blank" rel="noopener noreferrer nofollow">Vercel Pro or Enterprise</a> account
- An instance of [SigNoz Cloud](https://signoz.io/teams/)

## Configure Vercel Trace Drains

Follow the steps below to send your trace data from Vercel to SigNoz Cloud:

### Step 1: Create a New Trace Drain

1. Navigate to **Team Settings** > **Drains** and click **Add Drain**. This opens a dialog to configure your new drain.
2. Select the type of observability data you want to drain. In this case, choose **Traces**. The configuration options for Trace drains will appear.
3. Provide a name for your drain, select which projects should send data to your endpoint, and configure the sampling rate.
4. After configuring these settings, the **Next** button will be enabled. Click it to proceed.

<Figure
  src="/img/traces/vercel/sources.webp"
  caption="Vercel Drain Sources and Environment"
  alt="Vercel Drain Sources and Environment"
/>

### Step 2: Configure Destination

Choose how you want to receive your drain data. Under the **Custom Endpoint** tab, set the delivery format to `JSON` or `Protobuf` (Protobuf is recommended for performance). Vercel will now be configured to send payloads to your endpoint.

1. Enter the SigNoz OTLP HTTP traces ingestion **endpoint**:

```
https://ingest.<region>.signoz.cloud:443/v1/traces
```

Replace `<region>` with your [SigNoz Cloud region](https://signoz.io/docs/ingestion/signoz-cloud/overview/#endpoint).

2. Enable **Custom Headers** and add the following header:

```
signoz-ingestion-key: <your-ingestion-key>
```

Replace `<your-ingestion-key>` with the [ingestion key](https://signoz.io/docs/ingestion/signoz-cloud/keys/) from your SigNoz Cloud account. You can find this under **Settings > Ingestion Settings** in SigNoz. This ensures SigNoz Cloud authenticates and accepts your Vercel traces.

<Figure
  src="/img/traces/vercel/headers.webp"
  caption="Vercel Custom Headers"
  alt="Vercel Custom Headers"
/>

### Step 3: Test and Create the Drain

Click on **Test** to ensure your endpoint receives the data correctly. If successful, you will start to see sample traces on the SigNoz UI. After verifying the test results, click **Create Drain** in your Vercel dashboard.

Your Vercel traces will now be streamed to SigNoz Cloud.

</Admonition>

## Validate

After creating the drain, verify that traces are flowing into SigNoz:

1. Open **Traces** in your SigNoz Cloud dashboard.
2. Wait a few minutes for traces to arrive — there may be a short delay.
3. Look for trace entries originating from your Vercel projects.
4. If you see trace entries from your Vercel applications, the integration is working correctly.

## Troubleshooting
</ToggleHeading>

### No traces appearing in SigNoz

- **Incorrect region**: Verify that `<region>` in the endpoint URL matches your [SigNoz Cloud region](https://signoz.io/docs/ingestion/signoz-cloud/overview/#endpoint).
- **Invalid ingestion key**: Confirm the `signoz-ingestion-key` header value matches the key shown in your [SigNoz Cloud settings](https://signoz.io/docs/ingestion/signoz-cloud/keys/).
- **Drain not active**: Check the drain status in **Team Settings > Drains** in Vercel. If it shows an error, click the drain to see details.
- **Verification**: After applying fixes, click **Test** in your Vercel drain config and check the SigNoz Traces again.

### Drain creation or test fails

- **Endpoint URL format**: Ensure the URL is exactly `https://ingest.<region>.signoz.cloud:443/v1/traces` with no trailing slash or extra path segments.
- **Missing headers**: Confirm the `signoz-ingestion-key` custom header is set and the value does not contain leading/trailing whitespace.
- **Verification**: Once corrected, the **Test** button in Vercel should return a successful response.
