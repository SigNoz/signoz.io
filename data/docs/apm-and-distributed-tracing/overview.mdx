APM & Distributed Tracing in SigNoz gives you end-to-end visibility into your application's health and request flow. Monitor service-level RED metrics (Rate, Errors, Duration) and trace individual requests as they travel across microservices — all in one place.

## Key capabilities

- **Services view**: Monitor every service in your stack with latency percentiles, error rates, requests per second, Apdex scores, DB call counts, and external call counts at a glance.
- **Distributed tracing**: Follow a single request across all microservices with a flamegraph view that shows every span, its duration, and parent-child relationships.
- **Service map**: Visualize dependencies between services and spot latency or error hot-spots across your architecture.
- **Trace funnels**: Analyze how requests flow through a sequence of services or spans and identify drop-off points.

## Key product capabilities

### Services

The Services page surfaces RED metrics for every instrumented service:

- **Latency** — p50, p90, p99 response time trends
- **Error rate** — percentage of requests returning errors
- **Ops/s** — request throughput over time
- **Apdex** — user satisfaction score based on configurable thresholds
- **DB calls** — count and latency of database operations
- **External calls** — count and latency of outbound HTTP or gRPC calls

### Traces

The Traces section lets you search, filter, and inspect individual traces:

- **Trace explorer** — filter traces by service, operation, duration, status, or any span attribute using the Query Builder
- **Flamegraph** — visualize the full call tree for a trace, with each span's start time and duration
- **Span details** — inspect every attribute, event, and link on a span, including DB queries and HTTP payloads
