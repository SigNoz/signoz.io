## Additional Notes on GKE Autopilot

- For GKE Autopilot, the default storage class is `gce-resizable` and the cloud is `gcp/autogke`.

- GKE Autopilot automatically overriddes resource requests/limits. Therefore, it is important to ensure that the cluster has enough resource quota for the region where the cluster is deployed. Read more about it [here][3].

<Admonition type="info" title="Set the Autopilot values with Foundry" defaultCollapsed="true">
With Foundry, set the same values through a patch on the generated `values.yaml`:

```yaml
spec:
  patches:
    - target: deployment/values.yaml
      operations:
        - op: add
          path: /global
          value:
            cloud: gcp/autogke
            storageClass: gce-resizable
        - op: add
          path: /clickhouse/installCustomStorageClass
          value: true
```
</Admonition>
